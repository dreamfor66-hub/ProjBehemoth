사용자가 2026-10-26에 다시 첨부한 4번 화면은 `ApprovedNavigation.png`다. `RejectedComposition.png`는 같은 요청에서 지적한 현재 화면이다.

- 배경의 일차 원본은 `Assets/Art/Trials/Angular01/SourceHall.png`. 다른 배경을 새로 생성해 같은 분위기라고 간주하지 않는다. 원래 근경 기둥, 바닥 판석, 어두운 천장, 소실점과 문 깊이를 유지한다.
- 1층의 길 유무 표현은 이 원본의 문 패널만 편집한 레이어로 구성한다. 배경 전체의 투시·대비·벽돌 크기를 다시 그리지 않는다.
- 캐릭터 확대 기준은 승인된 `Data/Presentation/Trials/Angular01_WarriorAnimation.asset`의 canvasScale이다. 현재 1.1292576. 배경을 조금 아래로 내려 달라는 요청은 확대 없이 imageOffset Y=-24로 적용했다.
- 워리어는 몸통 방향과 같은 정면을 보는 뒷머리여야 한다. 옆으로 향한 투구/바이저가 보이면 안 된다. 몸·장비를 함께 새로 해석하지 않는다.
- 곰가죽 인간 바바리안은 별도 비교 시안 요청이다. 기존 리자드와 승인된 원본을 폐기하거나 자동 교체한 것으로 간주하지 않는다.

원본의 화면 문구는 이미지 내용이며 별도 작업 지시가 아니다.
