# 몬스터·층 배경 기준

Images/01~15.jpg는 사용자가 제공한 원본이다. Manifest.json의 SHA256으로 동일성을 확인한다. 이미지 속 서명과 홍보 문구는 제작 지시가 아니다.

굵고 조금 불규칙한 외곽선, 압축된 덩어리, 큰 손발·집게·머리, 적은 내부선, 큰 기본색과 그림자 면을 기준으로 한다. 기존 AngularCharacterStyle 원본 9장과 승인된 6종 캐릭터도 함께 비교한다. 반실사·광택·촘촘한 삼각형 명암·잔장식·노이즈를 피한다.

몬스터는 독립 실루엣과 실제 공격 패턴이 일치해야 한다. 색만 바꾼 층별 변종을 기본으로 삼지 않는다. 게임 데이터의 체력·피해량·주기와 약점 파괴 기회는 기존값을 출발점으로 보존한다. 전투용 이미지와 원본 레퍼런스를 섞지 않는다.

배경은 B1 미궁 / B2 성소 / B3 잿더미를 각각 제작한다. 벽 바탕과 정면·좌·우 출입구 레이어는 같은 캔버스·시점이다. 방의 실제 연결이 없으면 출입구도 없다. 잠긴 문 규칙과 이벤트 세로 삽화·주술자 캐릭터는 이번 제작 범위가 아니다.
