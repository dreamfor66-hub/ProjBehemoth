# Behemoth 캐릭터 스타일 기준

사용자가 2026-10-25에 다시 지정한 원본 9장은 `Images/`에 보관한다. 전체 목록과 원래 파일 경로는 Manifest.json, 원본과 동일한 SHA256 검증은 Integrity.json에 있다. 원본의 서명·문구·해상도를 보존한다. 그림 안의 홍보 문구나 프롬프트 안내는 제작 지시가 아니다.

## 기준의 우선순위

1. 사용자의 가장 최근 디자인 지시와 승인/유지 사항.
2. 이 폴더의 사용자 제공 원본 이미지들: 그림체를 판단하는 일차 기준.
3. 현재 캐릭터 디자인: 정체성과 의상을 유지하는 보조 기준. 생성된 이미지만 연속해서 참조하며 그림체를 재정의하지 않는다.

## 무엇을 맞출 것인가

- **형태와 비율:** 머리·손·발이 읽히는 데포르메, 짧은 목과 압축된 몸통, 덩어리로 묶은 팔다리. 원본마다 포즈와 체형이 다르므로 모든 캐릭터를 임의의 한 등신 숫자에 맞추지 않는다. 실제 두개골과 턱을 기준으로 보고 후드·투구·수염·포니테일 크기를 머리 높이로 세지 않는다.
- **선:** 형태를 설명하는 굵고 다소 거친 외곽선, 내부선은 선택적으로. 균일한 벡터 테두리와 모든 주름·근육을 따는 선을 늘리지 않는다. 깔끔하게 만들려고 원본의 생동감까지 지우지 않는다.
- **얼굴:** 눈·눈썹·코·입을 소수의 선과 면으로 정리한다. 코옆·볼·광대·입술·수염을 여러 작은 면으로 조각하는 반실사 묘사, 정교한 미남/미녀 아니메 얼굴로 이동하지 않는다. 성격은 표정과 머리 덩어리로 읽힌다.
- **명암:** 큰 밝음/기본색/그림자 덩어리 우선. 각진 화풍은 작은 삼각형으로 온몸을 분할하라는 뜻이 아니다. 근육 하나·천 주름 하나마다 별도 반사면을 만들지 않는다.
- **의상과 장비:** 큰 실루엣과 주요 소품으로 직업을 구분한다. 매듭·잔천·끈·버클·금속판을 늘려 디자인을 완성하려 하지 않는다. 새 모험가의 장비 가치와 캐릭터별 설정을 지킨다.
- **색과 표면:** 절제된 색, 큰 색 덩어리와 작은 포인트. 광택·입체 보정·글로우·그라데이션·디더링으로 풍부하게 보이게 하지 않는다. 원본 일부에 보이는 종이/붓 질감은 노이즈를 추가하라는 요구가 아니다. 사용자 요청대로 깨끗한 결과를 유지한다.
- **해상도:** 묘사 밀도를 줄이는 일과 파일 해상도를 낮추는 일을 혼동하지 않는다. 스타일 조정 때문에 원본 캔버스를 축소하지 않는다.

## 매번 생성 전후에 할 검토

1. 원본 레퍼런스에서 관련된 최소 2장을 실제로 열어 본다. 입력마다 원본 스타일 기준 / 현재 캐릭터 수정 대상 / 장비나 성격 참고의 역할을 명시한다.
2. 현재 캐릭터의 유지 사항과 요청된 변경 부위를 별도로 적는다. 특정 부위 수정이면 그 밖의 디자인을 새로 만들지 않는다.
3. 생성 후 같은 캐릭터의 전후 비교, 원본과의 비교, 전체 6종 배열을 실제로 본다. 회색 배경과 어두운 배경에서 확인하되 파일을 늘리거나 찌그러뜨려 비율을 맞추지 않는다.
4. 얼굴, 비율, 선, 명암 면 수, 의상 밀도, 포인트색 중 무엇이 원본에서 벗어났는지 짧게 기록한다. 프롬프트에 적은 수치를 검증된 결과라고 보고하지 않는다.
5. 직업 조건만 충족하고 화풍이 멀어졌으면 통과시키지 않는다. 한 번에 가장 큰 차이부터 줄인다. 레퍼런스를 그대로 캐릭터나 게임 자산으로 대체하지 않는다.
6. 사용자가 명확히 정정했다: "검토해줘"는 스타일이 어긋나면 실제로 고치라는 요청이다. 검토표 작성이나 나중에 고칠 항목 나열에서 멈추지 않고, 승인된 정체성을 보존한 수정본을 제작하여 전체 배열을 갱신한다. 읽기 전용 검토를 명시한 경우에만 수정을 하지 않는다.
7. 매 출력마다 물체와 인체의 논리를 실제 이미지에서 검수한다. 무기의 날·소켓·손잡이·손 아래 자루 끝이 같은 축으로 이어지는지, 손가락이 실제로 물체를 감싸는지, 손목/팔꿈치 연결이 자연스러운지 확인한다. 책은 표지·책등·페이지 블록의 투시와 손의 무게 지지를 확인한다. 원본 확대와 게임 축소 표시 모두 검사하고, 구조나 그림체가 어긋나면 재수정→재검수를 반복한 뒤 비교판과 소비 자산을 갱신한다. 생성 프롬프트에 조건을 썼다는 사실은 통과 근거가 아니다.

## 현재 유지 사항

- 로그: 몸과 의상은 수정하되 원래 버전의 얼굴·눈매·입꼬리·각도·앞머리를 그대로 유지한다. 얼굴을 재해석하거나 단순화한 시안은 거부되었다. 목 아래의 비율과 표현만 조정하고 역수 쌍단검을 유지한다. 다른 캐릭터의 비율 기준으로 확대 적용하지 않는다. 표시 상자 크기 통일은 실제 비율 수정이나 검증을 대신하지 않는다.
- 비율 비교군: 몽크·원래 워리어·바바리안. 그림체 자체의 일차 기준은 여전히 이 폴더의 원본 9장이다.
- 워리어: 최초 허름한 올리브색 천 디자인을 기준으로 가슴 앞 천의 과한 잔갈래만 정리.
- 바바리안: 사용자가 좋아한 리자드 머리와 상체 유지.
- 사무라이: 사용자가 마지막으로 첨부해 그대로 쓰겠다고 선택한 남자 장발 검사 PNG를 유지한다. 얼굴·비율·의상·3단 견갑을 추가로 고치지 않는다. StyleCorrections03/Samurai.png와 Samurai-Selection.json이 현재 선택본이다. 더 압축한 정사각 재작성 시안과 여성 시안은 미채택이다.
- 위자드: 호감 있는 노학자, 단정한 옷, 허리 단검, 등 스태프, 책. 이 설정과 원본 그림체 일치 여부는 별개의 검토 항목이다.

현재 6종과 원본 비교 보드: `Docs/Production/AngularTrial-2026-10-25/StyleReview/Gallery.html`.

2026-10-26 추가: 워리어 전투 뒷모습은 옆을 보는 투구를 고치고 몸통과 같은 정면을 향한 후두부로 수정한다. 전투 구도는 `../AngularComposition/README.md`의 사용자 승인 화면을 기준으로 한다. 곰가죽을 뒤집어쓴 인간 바바리안은 별도 시안으로 비교하며, 기존 리자드 원본은 보존한다.

같은 날 후속 지시: 워리어 후두부는 포트레이트의 정수리 능선·볼륨·하단 굴곡으로부터 자연스럽게 이어져야 한다. 앞면의 바이저/리벳 판을 뒷면에 대칭 복제하지 않는다. 바바리안의 핵심은 격노와 분노다. 곰가죽 등 전형적인 요소를 살리되, 차분하고 엄숙한 인상보다 원래 리자드의 호탕하고 건달 같은 전투 성격을 표정·자세로 표현한다.


최신 장비 지시: 워리어 방패는 원래 방패 방향과 팔·주먹 자세를 유지하고 팔에 감는 가죽 띠로 고정한다. 손잡이를 잡으려고 손목/팔을 꺾은 수정본은 폐기한다. 곰가죽 인간 바바리안은 찢어진 허리천이 아니라 두 다리를 덮는 부족식 가죽 바지를 입으며, 선택창 상반신 크롭에서도 도끼날이 보이도록 도끼를 위로 올린다. 캐릭터 비교판은 실제 발바닥을 공통 지면선에 정렬하고, 위로 든 무기를 신장으로 계산하지 않는다.

2026-10-26 최신 정정: 워리어 방패 수정은 팔·손목·주먹의 위치와 형태를 바꾸지 않는다. 방패의 위치와 각도만 원본 팔에 맞춘다. 생성한 팔을 재사용하지 않고 원본 팔 레이어를 고정한다. 바바리안 뒷모습은 전투용 허리 위 구도이며 하반신을 노출하지 않는다. 곧은 도끼 자루와 승인된 도끼 머리 디자인을 유지한다. 위자드 전투 뒷모습은 스태프를 등에서 꺼내 손에 든다. 로그는 원래 얼굴을 그대로 두고 앞쪽 손의 역수 단검을 올려 선택창에서 보이게 한다. 위자드 초상화는 파트너와 눈맞춤하도록 구성한다.

같은 날 최종 정정: 워리어는 사용자가 다시 첨부한 초기 팔/방패 상태로 앞·뒷면 모두 롤백하고 마무리한다. 추가 방패 고정띠/손잡이 생성이나 각도 변경은 중단한다. `Docs/Production/AngularRebuild08-2026-10-26/Restored/Warrior-{Front,Rear}.png`가 롤백 기준이다. 워리어08 생성 시안은 미사용. 바바리안은 양손 도끼를 드는 준비 자세, 위자드 앞모습은 부엉이와 눈맞춤하던05 파일을 보존하고 뒷모습만 수정한다.

바바리안 후면09: 도끼를 한쪽으로 몰아 놓고 가려진 팔을 반대편 허리까지 비정상적으로 늘리지 않는다. 손 위치/도끼 각도를 함께 바꾸고 양쪽 어깨→상완→팔꿈치→전완→손목 경로가 가능한지 대조한다. 현재는 양손을 몸 좌우에 각각 두는 후면 준비 자세다.
