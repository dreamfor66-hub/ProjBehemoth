# Tangba trial

- Requested reference: [탕바 — 눈누](https://noonnu.cc/font_page/1768)
- Author: [Monad ABXY](https://monadabxy.com/fonts/tangba/)
- Active source: `Tangba12.ttf`, proportional Regular, Version 1.1 from the author's
  [official TTF release](https://github.com/MonadABXY/tangba-font/releases/latest/download/Tangba-ttf.zip),
  path `Tangba-ttf/Proportional/Regular/Tangba12.ttf`.
- Reference web font retained separately: [Tangba12.woff2](https://cdn.jsdelivr.net/gh/projectnoonnu/2601-4@1.1/Tangba12.woff2).
  Its embedded version is 1.0; the unmodified official TTF is used for Unity.
- Native raster size: **12 px** (or integer multiples), as listed in the
  [author's size table](https://github.com/MonadABXY/tangba-font#권장-크기).
- License: accompanying [SIL OFL 1.1](OFL.txt), with the original notices retained.

This is an optional replacement for the Condensed face. In
`Assets/Data/Presentation/Typography.asset`, turn **Use Tangba For Condensed** off to
restore the original Galmuri11 Condensed choices. No font deletion, role changes or scene rebuild
is needed. Story, its Gothic alphanumerics and Galmuri7 keep their own roles.
