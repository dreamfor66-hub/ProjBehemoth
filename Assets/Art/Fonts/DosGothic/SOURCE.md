# DOS Gothic

- Requested reference: [도스고딕 — 눈누](https://noonnu.cc/font_page/239)
- Exact referenced web font: [DOSGothic.woff](https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_eight@1.0/DOSGothic.woff)
- Author/original collection: [leedheo — hurss/fonts](https://github.com/hurss/fonts)
- License: accompanying [MIT license](LICENSE.txt).

The WOFF container was decompressed to TTF with fontTools. Its glyph outlines were retained.
Only ASCII English letters A–Z/a–z and digits 0–9 are used in the project's DOS Story mixed source.
