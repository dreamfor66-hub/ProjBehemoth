## 실행 검증

기존 Unity Editor 하나에서 해당 동작만 확인했다. Live.txt 16개 항목 PASS, failures=0. 기본 1/2/3마리 실제 스폰 좌표, 플레이어 y=-532 및 그리기 순서, 내려간 왼쪽 몬스터의 약점 활성화/화면-논리 좌표/차지 공격 적중, 기존 두 종 encounter 배치, 비행형 자체 위치 보정 유지 확인. DPS/전체 회귀나 별도 Unity는 실행하지 않았다. 실제 모바일 기기 검증은 미실시.

예시와 수정 실행 화면을 동일한 화면비로 육안 대조했다. 중앙 몬스터 발 높이는 1080px 출력에서 약 724px로, 예시의 약 506/752 높이와 일치하며 좌우는 중앙보다 65 논리 단위 낮다. 이름/HP/그림/약점이 함께 내려온다. 검증용 임시 RectTransform 이동으로 화면을 만든 것이 아니라 저장된 Root와 기본 배치 함수를 사용했다.
