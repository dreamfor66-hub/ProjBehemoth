# 워리어 장검 길이 통일

사용자가 실제 빌드에서 긴 좌→우 Attack이 더 역동적이라고 판단하여, 직전의 축소 요청을 중단하고 현재 장검에 기존 Idle/우→좌 Ready의 칼날을 맞추도록 요청했다. 축소는 이미지 변경 전에 중단되었으며 적용하지 않았다.

- 현재 L→R Attack/Ready와 기존 우→좌 Attack/Guard는 바이트 동일하게 유지했다. After-Hashes.json 참조.
- 실제 Idle 참조 GUID를 확인했다. 사용자가 옮긴 현재 파일은 Assets/Art/World/Angular/States/Heroes/Warrior-Idle.png이다. 기존 GUID/메타, 프레이밍, 캔버스2896×1304와 입력 코드를 유지했다.
- 기존 Idle과 raised Ready의 노출 칼날만 수정했다. 현재 Attack의 칼날 길이에 맞춰 약800 원화 픽셀을 기준으로 잡았으며, Idle 약396px→800px, Ready 약484px→800px이다. 같은 무기라는 시각 판단을 위한 제작 기준이며 시스템 사거리를 바꾸지 않는다.
- 내장 image_gen으로 긴 칼날을 그렸다. 생성 과정에서 Idle의 검 각도가 달라지고 몸에 미세 차이가 발생해 전체 생성물을 덮어쓰지 않았다. 칼날만 분리해 기존 칼날 축·기부 폭에 등록하고, 칼뿌리와 손잡이 주변 원본을 유지해 합성했다. 몸/팔/손/방패/투구/천과 변경 영역 밖 원본 픽셀은 동일하다. 정적 PNG 원화 처리이며 런타임 키 모션을 추가하지 않는다. BladeRegistration.json에 위치·축·변경 영역과 일치 검사 기록이 있다.
- 사용자 원본 03-armored-hood-fighter.jpg / 04-brawler-back.jpg와 기존6종 비율·큰 명암 덩어리·제한 색·외곽선을 비교했다. 포즈나 장비 정체성은 재설계하지 않았다. 확대된 원화와 공통 배율 비교판에서 칼날 연결, 길이, 끝의 캔버스 여유를 확인했다.
- Art/AGENTS.md와 캐릭터 STYLE_GUIDE.md에 최신 기준을 저장했다. 캔버스는 채워야 하는 목표가 아니며, 선택된 무기 크기/동세와 여러 자세의 장비 일관성을 우선한다. 장검은 이번 실제 화면 판단으로 선택된 것이며 캔버스 확대 자체가 장비 크기 변경을 허가하는 것은 아니다.

Before/는 변경 전 원본과 메타, *-Generated.png는 내장 도구 원본, Warrior-Idle.png / Warrior-Ready.png는 실제 적용 파일의 사본이다. 정확한 프롬프트는 Prompts.json, 전후 비교는 Comparison.png다. 그림만 교체했으며 시스템/성장 수치 및 Unity 런타임 검증은 수행하지 않았다.
