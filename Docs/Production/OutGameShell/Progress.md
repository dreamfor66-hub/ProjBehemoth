캐릭터 선택 페이지에는 페이지 전환/스크롤이 없다. 포트레이트와 텍스트를 함께 보여준다. 본게임의 384×224/16색 및 기존 밸런스는 유지한다. OutGameScene은 원본 그림의 색을 보존한다.

실시간 검수에서 발견한 긴 유물 설명 넘침, 음량 슬라이더 겹침, 아트 복원 후 선택 테두리 소실을 수정하고 재검수했다. 전체 밸런스 스위트는 실행하지 않았다.

빌드에서 실제 전체 화면/창 크기 전환, 물리 모바일 입력은 별도 실기 검수 대상이다. Editor에서는 옵션 조작/PlayerPrefs 저장과 실제 AudioListener 반영을 확인했다. 테스트 후 원래 값(음량100%, 창3배, 전체화면 꺼짐, 흔들림 켜짐)을 복원했다. 상세 기록: Playtest.md.
