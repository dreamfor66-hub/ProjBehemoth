# Angular 01 — 두 화면 아트 방향 시안

새 참고 이미지의 각진 비례, 큰 손발, 굵은 윤곽선, 절제한 장비를 시각 언어로 삼아 만든 별도 시안이다. 참고 이미지의 인물·의상·포즈를 그대로 복사하지 않는다.

## 범위

- [x] 6직업의 새 전신 캐릭터와 선택 페이지 배치.
- [x] MainGameScene 첫 탐험 화면용 새 회랑, 워리어 뒷모습, HUD 초상화.
- [x] 별도 씬/데이터/렌더 설정으로 격리. 기존 원본 씬과 전투 밸런스 보존.
- [x] Unity 라이브 검증과 화면 캡처: 6직업 선택, 시작 버튼을 통한 시안 탐험 씬 진입, 최초 안내창의 계속 버튼, 안내 종료 후 첫 탐험 화면.
- 이번 시안에서 전투 애니메이션, 다른 직업의 전투 외형, 몬스터, 피로도 표정 및 후속 방은 확장하지 않았다. 워리어의 대기 이미지를 공격/방어 슬롯에도 임시로 연결했다. 시안의 목적은 첫 화면의 아트 방향 판단이다.

## 확인 위치

- `Assets/Scenes/Trials/Angular01_Characters.unity`
- `Assets/Scenes/Trials/Angular01_Main.unity`
- 원화와 시안 소비 이미지: `Assets/Art/Trials/Angular01/`
- 시안 전용 데이터: `Assets/Data/Presentation/Trials/`
- 시안 전용 플레이어 프리팹: `Assets/Prefabs/Trials/Angular01_Player.prefab`

원화는 Built-in image_gen으로 생성했다. 프롬프트 세트는 `Prompts.json`에 있다. 원본과 같은 네이티브 캔버스를 유지하고, 컷아웃 알파만 이진 처리한다. 이전 전역 7색/384p 변환으로 새 그림의 색 경계가 얼룩지는 것을 막기 위해 이 시안에는 별도 네이티브 크기 프레젠테이션과 원화 색면을 사용한다. 타이포그래피와 한국어 텍스트 키는 기존 TMP/CSV 경로를 유지한다.

시안의 워리어 플레이어 프리팹은 원화 색을 유지하는 기본 UI 머티리얼을 사용한다. 탐험의 뒤로 가기 버튼은 캐릭터의 머리와 겹치지 않도록 왼쪽 아래로 옮겼다. 위치는 시안 컴포넌트에 직렬화되어 있다. 플레이를 종료하면 선택 캐릭터와 백그라운드 실행 상태를 이전 값으로 복원한다.

`AngularTrialPreparation`이 프로젝트가 열리면 자동으로 소스 변경을 감지해 저장된 시안을 준비한다. 수동 베이크 메뉴가 필요하지 않다. 시안 씬에 저장하지 않은 편집이 있으면 덮어쓰지 않는다.
