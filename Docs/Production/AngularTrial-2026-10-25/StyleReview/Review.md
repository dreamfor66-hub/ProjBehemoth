# 전체 6종 스타일 수정 반영

사용자의 "검토해줘"는 어긋난 부분을 실제로 고치라는 요청이다. 검토표에서 멈췄던 이전 작업을 보완하여 이번에는 6종 전부 수정 파일을 제작하고 보드에 반영했다.

| 캐릭터 | 실제 반영한 수정 | 보존한 정체성 |
|---|---|---|
| 워리어 | 갑옷·칼·천의 잔반사면을 줄이고 큰 명암으로 통합 | 허름한 올리브 천, 투구, 초반 장비 |
| 바바리안 | 근육과 바지의 작은 명암 조각을 정리 | 승인된 리자드 머리·상체 디자인, 꼬리·도끼 |
| 몽크 | 팔 근육·바지의 면 분할과 허리 겹침을 줄임 | 눈가리개, 손동작, 큰 염주 |
| 사무라이 | 사용자 선택 이미지 그대로 채택 · 얼굴·비율·의상 유지 | 원래 남자 장발 검사, 강조한 견갑 |
| 위자드 | 반실사 얼굴을 단순한 카툰 얼굴로 다시 그리고 옷 명암 정리 | 온화한 노학자, 책·허리 단검·등 스태프 |
| 로그 | 짧아진 몸 비율을 유지하고 옷 명암만 정리 · 원본 얼굴 고정 | 원래 눈매·입꼬리·앞머리, 역수 쌍단검 |

## 재검토와 선택

- 각 캐릭터에 사용자 원본 스타일 레퍼런스 2장을 우선 제공하고, 현재 생성물은 의상과 정체성의 수정 대상으로 분리했다.
- 사무라이는 사용자가 다시 첨부한 이전 이미지를 명시적으로 선택했다. 해당 PNG를 바이트 그대로 채택했다. 더 압축한 재작성 시안은 미채택 이력으로 보존하며 얼굴·비율·의상을 추가 변경하지 않는다.
- 위자드는 첫 수정에서도 반실사 얼굴이 남아 해당 결과를 채택하지 않고, 원본 레퍼런스만 기준으로 얼굴·수염·머리·옷을 다시 그렸다.
- 로그는 첫 수정에서 다리가 다시 길어져 제외했다. 직전의 짧아진 비율을 유지한 국소 의상 수정 결과를 선택했다.
- 로그의 얼굴·눈매·입꼬리·앞머리는 원본 SourceRogue.png의 픽셀을 그대로 재사용했다. 최종 PNG의 지정 영역 38,700픽셀을 읽기 전용으로 대조하여 차이 0을 확인했다.
- 회색 및 어두운 배경에서 전체 배열, 캐릭터별 전후, 원본과의 비교를 확인한다. 이것은 미술 검토이며 자동 유사도 점수나 프롬프트에 적힌 등신 숫자의 달성 주장으로 대체하지 않는다.

## 파일과 표시

- 실제 수정본: Assets/Art/Trials/Angular01/StyleCorrections03/{Warrior,Barbarian,Monk,Samurai,Wizard,Rogue}.png
- 생성된 원래 캔버스와 RGB를 유지했다: 6종 모두 1024×1536. 해상도 축소나 팔레트 양자화로 밀도를 줄이지 않았다.
- 사무라이는 첨부 원본 그대로 복사했으며 알파도 변경하지 않았다. 나머지는 투명 가장자리 번짐을 정리했다. 로그의 원본 얼굴 영역은 그대로 보존한다.
- 보드 전체 배열은 투명 여백을 제외하고 균일 확대축소하여 가로세로 비율을 보존한다. 전후 비교는 각 이미지의 원래 캔버스를 보존해 표시한다.
- Before/에는 이번 수정 직전의 6종을 남겼다. 이전 검토 기록은 Review-Before-AllSix.md에 보존했다.
- 원본 9장은 Assets/Art/References/AngularCharacterStyle/Images/에 변경 없이 보관했다.
