# 캐릭터 6종 스타일 검토

현재 최신 시안 6종과 사용자 제공 원본 9장을 비교했다. 이후 사용자가 로그도 예외 없이 고치라고 지시하여 로그 명암 정리 시안 1종을 추가했다. Characters/에는 검토 PNG를 보관하고 로그 수정 전도 Rogue-Before.png로 남겼다. 각 출처는 Characters.json에 있다. 실제 Unity 씬에 6종의 최신 시안이 모두 적용되었다는 뜻은 아니다.

## 공통 결론

원본의 큰 실루엣과 소품은 따라왔지만, 현재 결과는 더 매끈한 외곽선·작은 삼각 명암·정교한 아니메/반실사 얼굴 쪽으로 이동했다. 특히 '각진 스타일'을 '몸 전체를 작은 다각형으로 조각하는 스타일'로 과하게 해석했다. 반복 편집에서 생성물 자체를 강한 기준으로 삼아 원본과의 거리가 누적된 점도 문제다.

원본은 넓은 빈 면을 남긴다. 명암 면이 있어도 큰 형태를 따라 선택적으로 들어가고, 모든 천·근육·금속에 같은 수준의 세부 명암을 주지 않는다. 스타일 복귀는 화질 축소나 소품 무조건 삭제가 아니라 이 선택적 생략을 회복하는 작업이다.

## 개별 검토

| 캐릭터 | 현재 원본과의 차이 | 유지할 것 | 다음 검토 우선순위 |
|---|---|---|---|
| 워리어 | 팔꿈치·정강이·칼·갑옷의 작은 반사면과 주름이 많고 전체 선이 지나치게 균일함 | 원본 실루엣, 투구, 앞 천 정리 결과 | 중간: 금속/천 명암을 큰 면으로 합치기 |
| 바바리안 | 근육과 바지에 삼각형 면이 반복되어 로우폴리처럼 보임 | 승인된 머리·상체 정체성, 굵은 꼬리, 짧은 바지 방향 | 중간: 디자인을 바꾸지 않고 내부 명암만 절제 |
| 몽크 | 양팔 근육, 바지 주름, 허리 매듭과 잔천이 모두 강하게 묘사되어 중심이 분산됨 | 눈가리개, 동작, 큰 손, 직업성 | 높음: 근육/천 면 수와 허리 밀도 정리 |
| 사무라이 | 원본들보다 긴 체형과 정교한 소년만화식 미남 얼굴, 여러 머리카락 갈래가 두드러짐 | 사용자가 복원한 남자 정체성·장발·견갑 | 높음: 얼굴/머리 덩어리와 선의 생략 검토. 임의로 다시 성별/의상을 바꾸지 않음 |
| 위자드 | 코·볼·눈가·수염·머리카락·손이 반실사에 가깝고 옷 명암도 많아 일행 안에서 화풍 차이가 큼 | 온화한 노인, 깨끗한 학자복, 책·허리 단검·등 스태프 | 가장 높음: 설정을 유지하고 얼굴과 명암을 원본 수준으로 간략화 |
| 로그 | 얼굴을 바꾼 1차 정리안은 거부됨. 현재는 원본 얼굴을 그대로 재사용하고 목 아래의 길이를 줄인 수정안 | 원본 얼굴·눈매·입꼬리·앞머리와 역수 쌍단검 | 얼굴은 고정, 몸과 의상만 조정. 전체 비율 기준 통과로 선언하지 않음 |

이 평가는 육안에 의한 미술 검토이며 자동화 점수나 실측 등신 결과가 아니다. 고정된 등신 수치보다 레퍼런스와 실제 나열 결과를 우선한다.

## 제안하는 다음 순서

1. 먼저 위자드의 얼굴과 내부 면을 단순화하여 기준에 복귀하는 시안 하나를 비교.
2. 같은 방식으로 몽크의 근육·천 면을 정리.
3. 워리어·바바리안·사무라이는 각자 승인된 정체성을 잠그고 표현만 조정.
4. 로그의 원본 얼굴은 고정하고 목 아래의 비율·선·의상만 조정. 최신 수정안에서 얼굴 영역 38,700픽셀은 원본과 차이 0을 확인했다. 같은 캔버스·같은 얼굴 크기에서 불투명 발끝은 y=1523에서 y=1314로 올라왔다. 자세도 바뀌었으므로 이 수치를 순수 등신 실측값으로 간주하지 않는다.

위자드·몽크·다른 캐릭터의 순서는 제안이며 이번 요청에서 실행하지 않았다. 로그는 얼굴을 다시 그린 시안이 거부되어 원본 얼굴을 재사용하는 목 아래 비율 수정안으로 교체했다. 전체 6종의 비율이 해결되었다는 평가는 하지 않는다. 다른 캐릭터의 긴 체형 문제도 남아 있으며 표시 상자를 맞춘 것으로 해결되지 않는다.

## 보드의 읽는 법

- 전체 6종: 최신 검토 시안을 동일한 이미지 상자에 비율을 보존하여 나열한다. 게임 내 실제 키 설정표나 정확한 머리 높이 정규화표가 아니다.
- 원본 9장: 원본 캔버스·워터마크를 그대로 표시한다.
- 나란히 비교: 현재 캐릭터와 원본을 직접 고르고 같은 표시 높이로 확인한다.
- 회색 / 어두운 배경: 배경 대비로 인한 인상 차이를 확인한다. PNG 픽셀과 팔레트는 수정하지 않는다.
- 소스 PNG의 반투명 가장자리 번짐은 그림 자체의 스타일 평가와 별도인 출력 품질 항목이다. 이 보드가 런타임의 알파 정리 결과를 재현한다고 주장하지 않는다.
