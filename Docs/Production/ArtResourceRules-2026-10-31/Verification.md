# 아트 리소스 정리 결과

- 아트 리소스 896개를 지정한 규칙으로 변경했다. 파일 이동은 Unity AssetDatabase로 수행해 GUID를 보존했다. 같은 그림의 PNG와 native Sprite에는 동일한 이름을 사용한다.
- 미사용 아트 및 폐기된 임포트 목록 267개와 해당 .meta를 삭제했다. 비어 있는 아트 폴더도 정리했다. 삭제 경로와 판단 근거는 DeletionAudit.md에 있다.
- 모든 비아트 에셋을 사용 루트로 간주했다. 따라서 게임 데이터나 씬이 참조하는 이전 그림도 보존했다. 사용자 제공 화풍 원본, 선택된 사무라이 원본과 현재 보스의 편집 소스도 보존했다. 제작 근거 문서는 리소스 삭제 대상에서 제외했다.
- 실행 코드에서는 두 개의 데이터 카탈로그를 Resources.Load로 읽으며, 해당 카탈로그와 모든 씬·프리팹·데이터의 직간접 아트 의존성을 사용으로 처리했다. 직접 경로를 사용하는 편집/검증 코드를 갱신하고 동적으로 구성하는 Sprite·Texture2D 로딩은 GUID 별칭으로 해결한다. 이전 DarkSeven 자동 임포트는 미사용 Import.json과 중간 원화가 삭제되어 다시 폐기안을 설치하지 않는다. 완료된 일회성 제작 도구는 기존 완료 표식을 유지한다.
- 유지한 에셋 2,187개의 GUID·직접 의존성, Sprite의 파일 ID·텍스처·크롭·피벗·테두리·PPU가 변경 전과 동일하다. 이전 경로 별칭 896개를 확인했고, 직렬화 파일 3,476개를 별도로 스캔해 삭제 GUID 참조가 없음을 확인했다. Audit.json의 오류는 0개다.
- 기존 Unity Editor의 실제 실행 검증은 **54 PASS / 0 FAIL**이다. 몬스터 44종, 캐릭터 6종의 그림 연결, 콘텐츠 UI 아이콘 160개, 실제 몽크 공격·겨울의 일각수 준비 그림·HUD 얼굴·포션 가방을 확인했다. RenamedCombat.png를 직접 검토해 표시를 확인했다. 검증용 런과 몬스터는 실행 중에만 변경했으며 종료 후 Play 모드를 해제했다.
- 입력·전투 수치·아트 픽셀 편집은 이번 작업에 포함하지 않았다. 물리 입력, DPS 비교와 전체 회귀 검증은 실행하지 않았다.

규칙의 지속 적용 위치: Assets/Art/AGENTS.md 및 프로젝트 AGENTS.md. 자동 삭제는 프로젝트 시작 시 실행되지 않는다.
