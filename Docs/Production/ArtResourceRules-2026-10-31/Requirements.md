# 아트 리소스 규칙과 정리

첫 정리의 ‘모든 프레젠테이션 데이터는 사용 중으로 인정’ 기준은 잘못된 판단이었다. 사용자 지적에 따라 고아 프레젠테이션 데이터와 그 종속 그림을 함께 삭제하도록 수정했다. 현재 정리 결과와 기준은 `Correction/Verification.md`를 따른다.

- [x] 캐릭터/몬스터 그림과 Sprite에 `T_Sprite_분류_이름_상태` 규칙을 기록하고 대상 경로를 생성한다.
- [x] UI 그림과 Sprite에 `T_UI_분류_이름`, 아이콘에 `T_UI_Icon_이름`, 공통 사각 패널/프레임에 `T_UI_Common_Rect_이름`을 적용한다.
- [x] Unity 의존성 그래프로 삭제 후보를 추리고 직접·간접 참조 및 코드의 동적 로딩을 점검한다.
- [x] 화풍/사용자 제공 참조 원본과 사용 중인 보스 그림의 편집 소스를 보존한다.
- [x] Unity에서 GUID를 유지하며 이름을 변경하고 확인된 미사용 아트를 삭제한다.
- [x] GUID·의존성·Sprite 파일 ID·크롭·피벗·PPU 및 현재 화면의 표시를 검증한다.

명명 대상은 프로젝트 아트이며, 정리 대상에는 미사용 프레젠테이션 데이터도 포함한다. 저장된 씬·프리팹·게임플레이 데이터에서 참조되지 않는 애니메이션 라이브러리는 그 종속 그림과 함께 삭제한다. 폰트·셰이더·TMP 패키지와 원본 참조 이미지는 별도 영역이다. 파일이 남아 있다는 사실 자체를 사용 근거로 삼지 않는다.
