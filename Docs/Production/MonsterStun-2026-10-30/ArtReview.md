# 원화 검수

내장 image_gen으로 각 몬스터 한 장씩 제작. 프롬프트는 Prompts*.json, 생성 출처는 Generated*.json에 기록했다. 모든 소비 PNG는 Assets에 복사했으며 외부 생성 폴더를 게임에서 참조하지 않는다.

실제 입력은 각 종 현행 Idle, 사용자 제공 EV GANIN 원본 두 장, 설치된 B1 배경이다. 원본의 선택적 먹선·소수의 큰 색면·단순한 얼굴과 현행 몬스터의 장비·팔레트를 비교했다. PoseReview-Dark.jpg와 PoseReview-Light.jpg는 같은 캔버스 비율을 유지한 Idle/기절 병렬 비교다.

| 종 | 기절 표현 / 검수 결과 |
|---|---|
| 경종 사냥개 | 고개와 귀·꼬리가 처짐. 두개골, 목줄과 종, 회녹색 유지. |
| 철갑 사마귀 | 무릎을 꿇고 큰 낫 팔을 내림. 작은 팔과 낫, 장갑 구분 유지. |
| 납골당의 종 | 종 몸체가 비스듬해지고 손이 아래로 늘어짐. 눈과 추 보존. |
| 실짜는 공작부인 | 머리·팔이 떨어지고 실이 느슨해짐. 상체와 거미 하체, 새 부리형 마스크 유지. |
| 미궁 스핑크스 | 앞다리가 굽혀지고 머리·날개가 낮아짐. 현행 크림 갈기·넓은 날개·금 목걸이 유지. |
| 쌍두 문지기 | 무릎과 한 손으로 버팀, 두 머리가 서로 다른 방향으로 처짐. 단일 돌 몽둥이 유지. |
| 고블린사냥꾼 | 창으로 버티며 머리·귀를 떨굼. 창, 허리 단검과 후드 유지. |
| 흡혈박쥐 | 비대칭으로 내린 날개와 처진 발, 고개. 날개를 접은 만큼 몸이 커 보이지 않도록 머리 폭 기준 정적 Sprite 스케일 보정. |
| 해골 전사 | 한 무릎을 꿇고 검끝·방패를 내려 버팀. 투구, 원형 나무방패와 손의 방향 유지. |
| 움직이는 갑옷 | 검에 기대 무릎을 꿇고 투구가 처짐. 생성 시 커진 몸은 기존 투구 폭에 맞춘 정적 Sprite 스케일 보정. |
| 실인형 | 조종 막대가 기울고 머리와 양팔이 처짐. 붉은 결속과 뼈 손발 유지. |
| 거미 | 다리를 접고 배·머리를 낮춤. 여섯 눈·두 큰 턱·8개 다리 구조 유지. 투명 외곽 수정본 사용. |

거미 초안의 검정 미리보기에서 외곽 번짐이 의심되어 투명 외곽 재생성을 요청했다. 최종 파일은 흰 배경 합성과 외곽 픽셀 alpha=0을 확인했다(SpiderAlphaReview.jpg). 투명 영역의 RGB 값 자체를 불투명 배경으로 오인하지 않도록 알파 채널을 별도로 검사했다.

두 무릎 자세의 고정 프레임 보정은 픽셀을 찌그러뜨리지 않고 native Sprite PPU에 저장한다. root의 종별 CombatScale과 그룹 배율, 판정 범위는 변경하지 않는다. 동일한 캐릭터가 단지 캔버스를 채우려고 커지는 현상을 방지하기 위한 보정이다. 단순화 검수는 원본 해상도와 축소판에서 진행했으며 PNG를 다운샘플링해 화풍을 흉내내지 않았다.

발밑은 현재 MonsterData 히트박스 최하단에서 한 번 계산해 Sprite pivot으로 저장한다. 기절 포즈를 구분하기 위한 회전·이동·스쿼시 또는 트윈은 없다. 최종 게임 내 크기와 전환은 Live.txt / *-Stunned-Live.png 기록을 기준으로 한다.
