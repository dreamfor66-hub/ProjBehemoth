- [x] 이름 피로도, 범위0~100,0은 사망.
- [x] 실제 이동 셀 수로 여유 소모. 같은 칸 재방문 포함, 벽/지도 확인 제외.
- [x] 공속 감소가 먼저, 일정 여유 후 최종피해 감소. 독/화상/주문/첫타도 포함.

- [x] 좌측 상단 표정 아이콘:6직업×4표정, 자세/테두리/색 변화 없이 얼굴 표정으로 구분.
- [x] 수치 상시표시 없음, 재사용 hover side popup에 피로도/단계/패널티.
- [x] 피로도10 이하: “더 무리해서 움직였다가는 죽을 수도 있다.”
- [x] 매 층 고정 캠프1개. 발견 후 사용하지 않아도 됨, 재방문 가능.
- [x] 야영1회: 피로도100, 체력10, 이동 여유 보충.
- [x] 반복 짧은 휴식: 피로도60까지, HP/여유/몬스터 재이동 없음.
- [x] 야영 후 살아 있는 일반 몬스터 이동, 보스/엘리트/캠프/기존 보상 고정. 처치 몬스터 재생성 없음.
- [x] 피로 회복 포션: 일반 공용 보상/상점 후보. 슬롯 강제 없음.
- [x] 한국어 CSV, 저장된 데이터/씬, 자동 에디터 준비, 아트 롤백 지원.
- [x] 기존 Unity에서 변경 부분 입력/회복/죽음/피해/지도 검증 및 실제224p화면 검수.

기존 Warrior/B1/B2/B3 수치 보존. 신규 피로도는 별도 최종 보정. 전체 밸런스 스위트와 추가 Unity 인스턴스 금지. 난수 습격/보스 이동은 구현하지 않음.

## 구현과 조정 지점

`Assets/Data/Behemoth/Settings/Fatigue.asset`에서 여유 걸음, 이동 소모, 공속/최종피해/주변부 흐림 곡선을 조정한다. 현재 초기값은 최소30보의 여유, 이후 성공 이동1회당2 소모다. 여유는 방 수의 절반 대신 왕복 탐색 거리 `2×(방수−1)`와 최장 시작거리의 합에55%를 적용하고 최소30보를 보장한다. 층 시작과 야영 때 보충한다.

| 피로도 | 공격속도 감소 | 최종피해 감소 |
|---|---:|---:|
|100|0%|0%|
|90|5%|0%|
|80|14%|0%|
|75|곡선 보간|0%|
|60|30%|15%|
|40|45%|35%|
|10|62%|70%|

각 값 사이에는 부드러운 곡선을 사용한다. 100에 가까운 소모 직후 강한 패널티가 오지 않고, 공속을 먼저 체감하게 한다. 주문·직접 무기 피해·독·화상도 최종피해 보정을 받는다. 대기/벽 입력/지도 열기는 자원을 소모하지 않는다. 하단에 새 게이지를 추가하지 않았다.

캠프는 층당 한 곳에 고정되며 지도에「야」로 표시한다. 미사용 상태로 나가거나 재방문할 수 있다. 야영/짧은 휴식/떠나기는 한 화면에 보이고, 자세한 효과는 기존 사이드 팝업을 재사용한다. 야영 때 살아 있는 일반 전투가 인접 빈 통로로 이동할 수 있다. 이미 지나온 빈 통로도 대상이며 원래 전투의 구성/난수 정체성은 보존한다. 공간이 없으면 이동하지 않는다.

추가한 기운 회복 포션은 피로도30과 이동 여유10보를 회복한다. 가격24, 기존 일반 포션 보상/상점 후보에 추가했고 보장 슬롯은 없다. 회복은 공용 `RecoverFatigue` 효과와 별도 `travelGraceSteps` 데이터로 구성했다. 피로도 유물은 아직 추가하지 않았다.

## 검증 기록

기존 Unity6000.0.59f2 인스턴스에서27개 집중 검사 PASS, 실패0. 원본 로그는 [Runtime-Checks.txt](Runtime-Checks.txt). 96개의 B1/B2/B3 지도에서 캠프 하나/연결성, 왕복/벽/대기, 실제 공격 간격, 직접/조준 주문/독/화상 피해, 포션 사용/상점, 야영/반복휴식/재방문/0 사망/다음 층 초기화를 확인했다.

실제 마우스로 짧은 휴식→결과→탐험 복귀 및 야영 선택을 확인했다. 여섯 직업의 네 표정24개, 경고 툴팁, 캠프 화면을384×224 원본 framebuffer로 검수했다. 표정 아이콘은32×32이며 각 상태의 이미지 크기/자세/테두리 색은 고정한다. 상태를 눈·눈썹·입의 변화로 전달한다. 예전 바스트 시안은 작은 크기에서 구별이 약해 얼굴 클로즈업으로 교체했다. 사건 화면을 빠르게 닫았다 열 때 전환 무늬가 남던 문제도 수정했다.

기존 아트 전환 구조에24개 얼굴/포션 참조를 등록했고 도형 모드에서는 캠프 그림을 숨긴다. 이번 변경의 전체 아트 롤백 스위트는 실행하지 않았으며 정적 참조와 표시 경로만 확인했다. 생성 도구/프롬프트/파일 경로는 [Art-Prompts.md](Art-Prompts.md).

**남은 검증:** 수치는 첫 플레이용 초깃값이다. 장시간 전체 층 탐험에서 캠프 발견 시점과 피로 압박의 체감, 직업별 완주 밸런스, 실제 모바일 기기 검증은 미완료다. 전체 DPS/밸런스 스위트는 실행하지 않았다.

별도 발견: 무작위 새 런을 여러 번 생성하는 중 DungeonGenerator의 기존 거리 조건 생성 재시도 한도를 초과하는 예외가1회 발생했다. 피로도27항목 통과 후 마지막 QA 초기화 단계였으며 캠프 배치 이전의 지도 거리 판정에서 실패한다. 이번 작업에서 지도 거리/시도 횟수는 바꾸지 않았다. 검증용 Fresh는 기존 ForcedSeed를 임시0으로 설정하고 finally로 복원하여 재현 가능하게 만들었다. 일반 플레이의 드문 지도 생성 실패 경로는 별도 수정 대상이다.

최종 인계: OutGameScene, Play 꺼짐, 씬 저장 상태 깨끗함. 저장된 QA 오브젝트 없음. 열린 씬 missing script0. 야영 패널의 화면 가장자리 HUD 조각을 가리고 마지막224p캡처를 다시 확인했다. 자동화는 기존 일시정지 상태 유지.
