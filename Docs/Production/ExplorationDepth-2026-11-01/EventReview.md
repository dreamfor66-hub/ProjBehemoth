# 사건의 시작·선택·재방문 검토

실제 설치된 `RandomEventData`의 시작문, 활성 페이지와 종결 선택, 고유 환경 오브젝트, 후속 상태를 함께 검토했다. `AfterEvents.json`은 설치 데이터 사본이다. 페이지가 있는 사건의 과거 단일 페이지 `options` 목록은 플레이 경로가 아니므로 활성 페이지와 구분했다.

거울은 일반 통로에 놓여야 할 이유와 선택 이후 물리적 결과가 약해 일반 추첨에서 제외했다. 대안으로 제작했던 회수대 쇠덫도 기술 습득·태엽 회수·동전 회수를 상호 배타적으로 만드는 근거가 약해 제외했다. 두 자료는 폐기 검토 이력으로 남겼다. 남은 활성 사건은 19개이며 기본 이벤트 방 수는 줄이지 않았다. 특정 사건을 시연하기 위한 고정 순서도 추가하지 않았다.

| 사건 | 화면에서 발견하는 대상과 미궁에 있는 이유 | 선택 뒤 공간의 결론 |
|---|---|---|
| 딱 하나 남은 열매 | 재배법이 달린 운반용 화분. 별도 온실이나 새 인물 등장 없음 | 열매/씨앗을 취하면 빈 화분·마른 줄기 상태. 미사용이면 그대로 |
| 길가의 무거운 금고 | 봉인 경고문과 돈주머니가 달린 독립 물건 | 소액 회수는 봉인이 굳고, 저주를 감수한 회수는 사용 상태. 다른 장소로 이동하지 않음 |
| 붉은 서명 | 목소리를 내는 봉인된 계약서 자체가 특수한 물건 | 서명/금박 회수 뒤 받침함까지 재로 사라지고 오브젝트 제거 |
| 끝까지 읽는 법 | 회수 기록 더미와 떠 있는 책. 세 막의 기록 보관 틈새 배경 사용 | 독서 뒤 책이 다시 떠오른다는 결론과 남는 그림 일치. 완료 뒤 재독 보상 없음 |
| 어디까지 풀 것인가 | 운반 장비에 묶인 훈련 인형과 내부 보상함. 전용 장비 틈새 배경 | 선택한 구속 수준으로 전투 후 인형 정지·구속구 소진. 물건의 도전 보상임을 처음부터 설명 |
| 주인 잃은 깃발 | 깃발에 묶여 남은 가시 짐승. 인카운터 실체가 처음부터 보임 | 급료만 취하면 짐승이 남고, 전투 승리 뒤 쓰러진 소진 형태 |
| 이름 없는 회수표 | 회수업자로 위장해 살아 있는 원정객을 노리는 도적 | 전투하면 쓰러진 형태, 돈/마력으로 피하면 통로로 떠나 제거 |
| 회수표를 단 개 | 회수대 추적견. 끊어진 작업용 쇠줄과 앞발 부상 | 구조하면 환경 그림 제거 후 같은 회수견이 동료로 합류. 떠나면 경계하며 남음 |
| 꺼진 기도 | 부상자를 먼저 보낸 후 발목을 다친 후송 성직자 | 치료/약초 강탈 뒤에도 같은 인물이 남음. 소진 대사는 선택에 따라 달라짐 |
| 끊어진 호위 | 계약자의 잘린 밧줄을 쥔 부상 용병. 귀환해 따질 목적이 있음 | 붕대를 돕고 일어서면 떠남. 품삯 강탈/방치하면 부상자가 남음 |
| 그 돌에 적힌 이름 | 회수소 심부름을 하다 아버지의 회수 증빙을 확인하러 온 소년 | 해결/강탈 뒤 이동해 제거. 미해결 방치는 같은 인물이 길을 살핌 |
| 짐 하나만 부탁하네 | 귀환 계약을 위해 이름 돌과 유품을 운반하는 회수인 | 도움/강탈/회수견 안내 뒤 떠남. 대화에서 갑자기 다른 장소가 나타나지 않음 |
| 배달지는 다음 막 | 여러 상점 납품표와 저당 운반틀을 가진 짐꾼 | 예약/강탈/거절 모두 다른 통로로 이동. 예약 건만 후속 배달 대상 |
| 상자가 두 개다 | 먼저 예약한 표식과 쪽지가 붙은 배달 꾸러미. 짐꾼이 갑자기 등장하지 않음 | 장비 또는 기술을 대가로 한 여비를 취하면 사용된 꾸러미 상태 |
| 번개를 파는 행상 | 공방에 병값을 갚으며 독립을 준비하는 현장 행상. 밀랍 봉인을 확인함 | 거래/강탈 뒤 짐을 꾸려 떠남. 그냥 떠나면 행상은 남음 |
| 금빛 이빨의 내기 | 생환 채권을 현장에서 거래하는 장부 중개인 | 내기/강탈 뒤에도 장부를 든 인물로 남음. 무료 재거래 대신 완료 반응 |
| 귀환로의 측량사 | 옛 귀환 지도와 현장 표식을 대조하는 지도 납품 마법사 | 길 정보와 주문 교환/매입금 강탈/거절 뒤 조사 통로로 이동. 불붙은 종이·후방 습격 전제 제거 |
| 성장한 제자 | 이전에 만난 측량사가 조사 도중 교본으로 주문 사용 경험을 확인 | 교습/강탈 뒤 지도와 교본을 챙겨 떠남. 기존 후속 조건 유지 |
| 지팡이 끝의 수업 | 더 깊은 조사 경로에서 같은 측량사가 다음 교습 제안 | 교습/수정 강탈 뒤 떠남. 이전 주문·후속 사건 조건 유지 |

NPC는 무조건 사라져야 하는 규칙으로 처리하지 않았다. 떠나는 선택은 실제 오브젝트를 제거하고, 남는 선택은 인물의 현재 상황과 소진 대사를 유지한다. 사건별 고유 그림과 기존 선택 비용·효과를 보존했다. 새 인물/공간이 필요 없는 물건과 몬스터 조우는 해당 실체로 시작한다.

이번 시각 보정은 회수견, 측량사, 짐꾼·중개인·병 행상의 정면/측면 표정과 무게, 분수, 문틀에 집중했다. 나머지 사건 그림을 전부 새로 제작했다고 간주하지 않는다. 공급된 다키스트 던전의 눈·검은 덩어리·작업 장비·지면 접촉과 비교한 구체적 기준 및 결과는 `ArtDirection.md`, `Verification.md`에 기록한다.
