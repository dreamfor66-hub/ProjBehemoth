# 방문한 방의 지도 공개 유지

- [x] 방문한 방은 현재 위치와의 거리, 클리어 여부, 생성 시 공개 플래그와 관계없이 계속 표시.
- [x] 미방문 방은 현재 방에 연결된 가까운 목적지만 표시. 생성 시 상자/정예/보스에 설정한 `IsRevealed`는 멀리 있는 방을 노출하는 근거로 사용하지 않음.
- [x] 방문했던 입구·상자·정예·보스의 공개 상태가 이동 후 및 지도 닫기/재개방 후 유지됨.
- [x] 가까웠지만 방문하지 않은 방은 멀어지면 다시 숨겨짐.
- [x] 기존 Unity Editor Play 모드에서 실제 저장된 지도 UI로 관련 상태 10개 확인, 실패 0. `Live.txt`, `Complete.txt`, `Visited-Memory.png` 참고.

표시 조건은 `DungeonMapView.Render`에서 `IsVisited` 또는 현재/인접 방인지로 계산한다. 방문 이력은 기존 `PlayerDungeonState.MoveTo`가 기록하는 `IsVisited`를 그대로 사용하며, 별도 중복 상태나 디자이너 설정을 추가하지 않았다.

검증은 사건 진행을 일으키지 않는 7개 방의 런타임 지도 fixture를 사용했다. 원래 미궁의 내비게이션 갱신을 중지해 fixture 화면과 섞이지 않게 하고, 완료/미완료 방과 강제 공개 플래그를 각각 확인했다. 지도 화면 밖의 기억된 방은 기존 드래그로 볼 수 있다. 이번 변경은 가림막의 표시 대상 규칙만 다루며 이동 입력·전투·밸런스 전체 검사는 실행하지 않았다. 검사 후 Play 모드를 종료했다.
