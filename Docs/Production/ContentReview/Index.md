## 이번 반영

「병 속의 폭풍」「뇌성의 대검」의 차지 적중 번개 피해 8에 번개 피해 증가가 적용되도록 데이터 효과를 수정했다. 기본 피해와 트리거는 유지했다. 생성용 이전 레시피에도 같은 수정을 남겼다. 신규 속성 전환 유물이나 희귀도는 추가하지 않았다.

교환 선택지를 포함한 아래 **5개 사건 전체**를 무작위 출현에서 제외했다. 선택지·서사 자산은 향후 재설계를 위해 보존했고, Inspector의 excludedFromRandomPool로 관리한다. 다른 사건의 단순 강화나 퍽→골드 전환은 유지했다.

| 제외한 사건 | 해당 선택 | 함께 중단되는 보상 경로 |
| --- | --- | --- |
| 두 번째 맥박 | 퍽 1개 제거 → 새 퍽 선택 | 공생하는 씨앗의 유일한 입수처 |
| 내일의 한숨 | 퍽 1개 제거 → 새 퍽 2회 선택 | 깨어진 모래시계의 유일한 입수처 |
| 소리 나는 쪽을 받쳐라 | 공용 유물 제거 → 수호의 종 | 수호의 종의 유일한 입수처 |
| 날이 아니라 버릇을 간다 | 퍽 1개 제거 → 새 퍽 2회 선택 | 이 사건의 강화/최대 실드 증가 선택도 중단 |
| 문이 이름을 틀리게 부른다 | 퍽 1개 제거 → 새 퍽 2회 선택 | 이 사건의 전용 유물 전투/체력 증가도 중단 |

「상자가 두 개다」의 퍽 제거→100골드 선택은 새 퍽/유물 교환이 아니므로 유지했다. 「오늘의 상대를 고르시오」의 기존 퍽 강화도 유지했다.

## 검증과 범위

기존 Unity Editor에서 **20개 집중 검증 통과**. 두 유물 각각 일반타 미발동, 기본 8, 번개 퍽 1중첩 8.8 / 2중첩 9.6, 화염 퍽 비영향, 물리 차지 기본값 유지, 모든 피해 +25%와 번개 +20% 동시 적용 시 12를 확인했다. B1~B3 총 384회 사건 추첨에서 제외 사건 미출현을 확인했고, 제외 사건만 있는 풀에서는 사건이 나오지 않았다. [검증 로그](Runtime-Checks.txt). 전체 DPS/밸런스 검증은 실행하지 않았다.

범위: GameContent의 퍽 41 / 장비 102 / 주문 16 / 사건 23 및 MainGameScene의 실제 퍽 41 / 장비 98 목록을 대조했다. 102 장비는 유물 84 + 일반 주문서 12 + 포션 6이다. 84 유물 중 현재 경로가 있는 것은 78종이다. 파일만 남은 이전 프로토타입 퍽이나 PerkAbilities 내부 효과 자산은 현행 선택 가능한 별도 콘텐츠로 세지 않았다. 일반 해금은 없고, 시기는 최초 입수 가능한 구간이며 등장 보장은 아니다.
