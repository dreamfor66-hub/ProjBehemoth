# 유물 목록 · 84종 + 일반 주문서 12종

시작 6종 / 공용 17종 / 직업 전용 48종 / 이벤트 전용 13종 = **유물 84종**. 이 중 **현재 입수 가능 78종**, 사건 제외로 중단 3종, 보상 목록에 빠진 공용 3종이다. 일반 주문서 12종은 별도 표로 구분했다. 포션 6종은 유물에 포함하지 않는다.
