## 설명과 효과 데이터가 일치하지 않는 항목

| 항목 | 설명 | 조사된 데이터/코드 |
| --- | --- | --- |
| 사냥꾼의 등불 | 처치 시 HP 7 회복 | 장비 능력 목록에 OnAcquire/Owner/ExtraAttack0만 있고, 처치 회복이나 MonsterKillHeal 보정이 없음. 별도 additionalModifiers도 비어 있음 |
| 번개 심줄 | 일반 피해 +20%, 쿨타임 -12% | 장비 능력 목록에 OnAcquire/Owner/ExtraAttack0만 있고 해당 스탯 효과가 없음. 이름과 달리 번개 피해도 없음 |
| 수호자의 방패 | 초당 가드게이지 2.5 회복 | 현재 자산은 OnAcquire에서 GuardRecoveryPerSecond0.25를 설정. 일반 재생 스탯은 Warrior에서0. OnAcquire RuleModifier는 Stage 수명의 임시 버프를 만들고 BeginCombat이 이를 정리하는 경로라 설명과 차이가 있음. 이 항목은 정적 코드/자산 대조 결과이며 별도 실전 확인·수정은 하지 않음. 디자이너 Warrior 기준 보존 |
| 핵심 회수 | 약점 타격 시 실드 +10 | 실제 트리거는 OnWeakPointBreak. 모든 약점 타격이 아니라 약점 파괴 시점 |
| 잿불 화살의 마도서 | 낮은 체력 비율 적을 자동 겨냥 | 실제로 배우는 주문은 이름이 바뀐 파이어볼트이며, 현재는 그은 방향으로 날리는 방식 |

두 유물의 비어 있는 효과는 실제 카탈로그와 플레이 보상 목록 양쪽에 있어, 이름만 있는 미사용 자산 문제가 아니다. 위 두 항목의 효과 미연결은 정적 데이터로 확인했으며 이번 런타임 검증은 요청된 번개 유물/사건 출현에만 한정했다.

## 속성 빌드 관점에서 드러난 구성

- 무기의 기본 피해를 화염/냉기/번개로 **전환하는 유물은 아직 없다.** 인챈트는 무기 적중에 원소 피해를 추가한다. 기본 물리 피해를 바꾸지 않는다.
- 「병 속의 폭풍」은 이벤트 전용,「뇌성의 대검」은 바바리안 전용이다. 둘 다 차지 적중에 번개8을 추가하며 이번 수정으로 번개 피해 퍽이 적용된다. 커먼/레어 희귀도 자체는 현재 구현되어 있지 않다.
- 원소 퍽은 B1 첫 레벨업부터, 인챈트 포함 12종 일반 주문서는 B1 상자/상점부터 나온다. 이미 배우지 않은 일반 주문서에는 메타 해금·선행 주문 소유 락이 없다. 인챈트의 별도 앞구간 우선 배치는 하지 않았다.
- 「벼락표식」은 다른 적에게만 피해를 전달하므로 기본 1대1에서는 효과를 쓸 대상이 없다. 「인챈트 라이트닝」은 본 대상에게 번개4가 남지만 추가 번개2의 다른 적 전달은 쓰지 못한다.
- 「번지는 맹독」「사냥은 계속된다」「이름 없는 깃발」도 처치 후 전파/지속 또는 적 수에 의존한다. 존재 여부와 효과만 목록에 기록했으며 이번에 재설계하지 않았다.
- 회복이 달린 유물은 여전히 여럿 있다: 피의 연회, 맹독의 생명줄, 피를 거두는 칼집, 생명의 초식, 사냥은 계속된다 등. 기존의 HP 관리 방향과 맞는지는 다음 검토 대상이다.
- 전용 유물 상한은3개지만 현재 일반 진행은 B1·B2 보스 뒤 두 번의 선택만 남는다. 추가 전용 유물 경로였던 MasterTrial을 제외한 영향이다.
- 일반 퍽 대부분의 실제 중첩 상한은99다. 위자드「축약 영창」12, 치명타 공용 퍽2종은 각각5다. 기획상 기대하는 적정 최대 횟수로 다시 조정한 상태는 아니다.
