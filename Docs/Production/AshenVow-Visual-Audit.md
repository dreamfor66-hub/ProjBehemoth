# 잿빛 서약 — 비주얼 검수

2026-10-23. 가제 **ASHEN VOW / 잿빛 서약**. 실제 Unity Game 화면을 확인하고 네이티브 게임 캡처를 보관했다.

## 방향과 판정

사용자가 요청한 `pixel dark fantasy game` 검색 결과와 [Blasphemous](https://store.steampowered.com/app/774361/Blasphemous/)를 분위기 참고로 삼았다. 이미지 자체는 새로 제작했다. 검은 석조 성 내부, 촛불과 잿빛 청색의 대비, 낡은 철·뼈·금색, 인물과 괴물의 구체적인 실루엣으로 방향을 통일했다.

**다크 판타지 게임의 화면 구성과 소재는 충족한다.** 도형 캐릭터·임시 유물 이미지를 포트레이트, 전투 스프라이트, 개별 유물 아이콘으로 교체했다. 픽셀 군집과 디더링이 보이는 고해상도 픽셀풍이며, 16×16 타일 규격으로 통일된 저해상도 도트 게임과는 질감이 다르다.

| 화면/소재 | 확인과 수정 |
|---|---|
| 캐릭터 선택 | 6명 고유 포트레이트, 큰 일러스트, 시작 유물·조작법, 한글 가제와 영문 로고 |
| 성 내부 | 지하 성채/얼어붙은 묘실/용광로의 층별 배경. 공격 대상과 플레이어의 공간을 확보 |
| 적 | 실제 디자이너 B1/B2/B3 몬스터에도 아트 연결. 박쥐 프레임에 인접 도끼가 보이던 아틀라스 잘림을 재제작·실루엣 기준 스프라이트 범위로 수정 |
| 동료 | 기존 도형 동료를 떠돌이 개 스프라이트로 교체, 작은 호흡/이동 반응 |
| 유물·퍽·주문 | 개별 래스터 아이콘. 이미지에 임시 색상이 곱해져 어두워지던 바인딩 수정 |
| 사건 | 성 안 사건 삽화, 문단 단위 진행, 선택 비용과 결과, 디더 전환. 일러스트에 플레이 HUD가 겹치지 않게 전투 HUD 숨김 |
| 퍽 선택 | 큰 아이콘, 효과 문구 확대, 카드 여백과 줄바꿈 확인 |
| 상점 | 유물/포션 아이콘, 가격·구매 가능/골드 부족 상태, 별도 설명 영역 |
| 한글 | Galmuri11 기반 TMP 폰트, 텍스트 키/CSV 유지. 선택·사건·보상·상점 화면의 한글 표시 확인 |
| 전투 HUD | HP/실드/MP와 주문 비용·쿨다운. 대기 중에는 주문명, 영창 중에는 시전 상태. 개발 진단 패널은 상시 표시하지 않음 |

폰트는 [Galmuri](https://github.com/quiple/galmuri), OFL 라이선스를 함께 보관했다. 생성 아트의 프롬프트와 출처는 `Art-Sources-and-Prompts.md`에 기록했다.

## 캡처와 한계

`Screenshots/Selection.png`, `Teacher.png`, `Perks.png`, `Shop.png`, `Combat.png`는 실제 게임 화면이다. 전투 캡처에는 주문 표시를 위한 QA 전용 런타임 적 복제본이 사용되며 원본 밸런스에는 저장되지 않는다.

검수는 현재 에디터의 2560×1440 Game 출력에서 수행했다. 작은 물리 모바일 화면의 글자 크기와 실제 양손 터치는 기기 검수가 남아 있다. 전투 캐릭터는 스프라이트의 호흡·피격·공격 반응 수준이며, 모든 동작을 프레임 애니메이션으로 새로 제작한 것은 아니다.
