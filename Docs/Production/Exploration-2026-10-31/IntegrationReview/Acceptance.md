## 반려하고 수정한 사항

첫 화면 재검수: 밝은 별도 석조 아치 중첩, 떠 있는 아이콘 열쇠, 낮은 벽장치가 주인공에게 가려짐, 근거 없는 전경 확대/비대칭 배치, B2/B3 조명과 무관한 원색 표시, 그림 전체 hover 밝기 변화.

첫 Unity 비교판: 마른 분수 측면이 원래보다 높아짐, 유리 덮개 측면의 불투명한 흰 면, 상인 퇴장 후 짐이 사람의 전체 발폭에 맞춰 확대됨. 각각 원화 수정/별도 aftermath 데이터로 수정한다. 이미지의 그림자를 물체 지지 폭으로 오인하는 계산도 수정한다.

검수 장면은 별도 Editor 전용 probe에만 존재한다. 실제 플레이의 생성 가중치/이벤트 배치에 검수 순서를 삽입하지 않는다. 실제 플레이 경험의 밀도·의외성·반복감은 사용자의 정상적인 1~3막 플레이 피드백으로 판단한다.

## 최종 결과

61개 개별 PNG, 17개 편집 가능한 오브젝트 데이터. PNG 10개를 교체했고, 문 측면의 별도 석조 아치 그림은 참조 및 경로 로드 검색 후 제거했다. 원래 GUID/메타는 교체한 PNG 모두 보존했다. 평면 문짝은 배경 9개 입구의 내부 윤곽과 소실점에 맞춰 표시한다. 삭제한 문 측면 원본은 BeforeArt에 보존했다.

273개 실제 Unity 화면(1~3막 × 모든 가시 방향/사용 상태), 모든 화면의 입력 영역/hover 조명 검사 실패 0. Runtime/Complete.txt와 Input.txt, B1~B3-Review-01~08.jpg에 기록했다. 사용 전후 분수의 돌 몸체가 유지되고, 유리 프레임에 흰 불투명 면/얼룩이 없으며, 인물의 읽히는 얼굴과 바닥 접촉을 재확인했다. 첫 유리 수정본은 흰 테두리 얼룩으로 반려했고 설치하지 않았다. 방향 3벌 및 수확 후 3벌을 함께 다시 제작했다.

초기 8개 입력 충돌은 InitialInputMismatch.txt에 남겼다. 검수용 방의 벽/문 상태와 이동 버튼이 불일치했던 점을 실제 통행 규칙을 사용하는 격리된 검수 방으로 수정했고, 실제 소품의 오른쪽 안쪽 배치를 조정했다. 이후 인물 얼굴과 버튼의 가림도 비교판에서 확인하여 바닥 슬롯을 안쪽으로 조정했다. 이동 버튼의 원화/위치는 변경하지 않았다.

최종 기능 검사 81항목 실패 0(LiveComplete.txt). 생성된 방의 진입로 수에 따른 여신상 방향 검사 개수 차이로 이전 77/79회와 총수가 다르며, 새 실패를 제외해서 숫자를 줄인 것이 아니다. 분수 거절/재열기/사용/마른 상태/재조사, 상자 실제 선택/중복 방지, 숨은 입구/잠금/열쇠/진입, 이야기 aftermath, 독 분수와 미믹의 실제 전투를 포함한다.

computer-use 직접 검사: 2026-10-31 최종 제작 후, 사용자의 기존 Unity Editor 한 개에서 분수 클릭 → 거절 → 재열기 → 사용 → 결과 닫기 → 동일 몸체의 마른 분수 → 재조사 시 팝업이 열리지 않음을 확인했다. 짧은 소진 나레이션의 실제 렌더링은 B1-Fountain-Used.png에 기록되어 있다. 검사 후 Play를 종료했고 이벤트 이력/백그라운드 실행 설정은 probe가 복원했다. 5회 정상 플레이의 경험 평가는 사용자의 후속 피드백 대상이다.

검사 종료 로그에서 기존 DarkArtPreparation의 장면 열기와 예약된 Play 전환이 겹치는 예외 1건을 발견했다. 장면 열기 직전의 Play 전환 가드를 보강하고 검수 시작을 Editor delayCall로 넘겼다. 수정 후 81항목 전체를 다시 실행하여 실패 0, 추가 오류 로그 0바이트를 확인했다. 새 Unity 인스턴스/광범위 DPS 검사는 사용하지 않았다.
