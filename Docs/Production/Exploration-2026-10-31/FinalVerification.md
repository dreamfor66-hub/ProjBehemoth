# 최종 검증

> 최신 배경/합성 판정은 BackgroundRevision/Review.md가 대체한다. 아래 computer-use 기록은 배경 재제작 전 검사다. 이번 2/3막 배경 재제작 이후 직접 computer-use 검사는 도구 연결이 없어 미실시이며, 실제 Unity 캡처/입력 및 기능 검사를 별도로 기록한다.

- 기존 열린 Unity Editor에서 컴파일 성공. 기존 RewardPopupView.animation 이름 경고 1건은 이번 변경과 무관하다.
- 1~3막 변경 상호작용 최종 결과는 Live.txt / LiveComplete.txt에 기록했다. 생성된 방의 진입로 수 때문에 여신상 방향 검사 개수는 실행마다 달라진다.
- 분수·상자 미사용/소모·재조사, 상인 대화 거절, 여신상 벽/입장 방향, 야영지 휴식, 성직자 실제 선택과 재방문, 숨은 방 지도 비노출, 발견/잠금 분리, 열쇠 1회 획득/소모, 열린 통로 실제 이동, 수집한 모래시계의 빈 탁자, 독 분수와 미믹 전투 진입을 확인했다.
- computer-use는 구현/그림 작업 종료 뒤에만 실행했다. 마우스로 월드 분수를 열고, 사용하지 않고 닫은 뒤 다시 열기, 실제 사용 선택/결과 닫기, 마른 그림으로 돌아오는 흐름을 확인했다. 선택 버튼은 누름/뗌이 프레임을 가로지르도록 1px 이동 입력으로도 확인했다. 소모 후 비모달 나레이션과 중복 회복 방지는 3막 모두 런타임 검사에서 확인했다.
- 일반 시드 64개×3막의 구조 검사는 GenerationAudit.txt: 실패 0. 별도의 시연 순서나 테스트용 생산 배치는 없다.
- 후속 엄격 아트 검수: 최종 61개 개별 PNG(10개 교체, 기존 문 측면 1개 제거), 17개 오브젝트 데이터. 273개 실제 Unity 화면에서 방향·막·소진 상태를 비교하고 모든 입력/hover 조명 검사 실패 0. 최신 결과는 IntegrationReview/Acceptance.md / InstalledFinalArt.json / Runtime/Complete.txt.
- 테스트 오브젝트와 실행 중 상태는 Play 종료와 함께 제거하고 사건 이력 설정을 검사 전 값으로 복원했다. 다음 Play는 일반 새 게임으로 시작한다.

사용자가 일반 플레이 약 5판에서 평가할 발견 밀도·반복감·놀라움·긴장도는 미검증 경험 영역이다. 전체 DPS/밸런스 비교와 실기기 검증은 실행하지 않았다.
