# 1~3막 탐험 경험

MainGameScene과 Angular01_Main에 탐험 오브젝트/입력 슬롯을 저장했다. 모든 막이 동일한 데이터 기반 표현을 사용하며, 기존 막별 적·미믹·독 분수 등장 자격과 전투 수치는 유지한다. 화살표 그림과 둘러보기 조작은 작업 범위에서 제외했다.

- 기존 자동 이벤트 일부는 유지하고, 일부는 사물/인물을 눌러 시작하도록 저작했다. 방에 처음 배정된 이야기는 재방문해도 다시 추첨하지 않는다.
- 숨은 입구와 잠금은 독립 상태다. 발견 전의 통로와 방은 지도/이동 대상에 노출하지 않고, 발견 후 잠긴 문은 지도에 기록된다. 열쇠는 잠금 바깥의 도달 가능한 기존 방에 놓인다.
- 선택적 방은 기존 층 생성 후 추가하는 막다른 가지다. 기존 성장/회복 방을 대체하지 않는다. 강제 전투는 낮은 비율로 설정했으며 별도의 시연 순서나 다섯 판용 고정 배치는 없다.
- 상자/분수/상인/여신상/야영지와 저작된 사건 사물은 실제 선택에 따라 남는다. 미사용 상자/분수는 다시 선택할 수 있고, 소모 후에는 보상을 반복하지 않는 짧은 나레이션으로 반응한다.
- 방의 고정된 방향/모서리를 입장 방향에 맞춰 표현한다. 여신상은 막힌 벽이 있는 방에 배치한다. 그림은 배경 아래 계층, 입력은 캐릭터 그림 위·이동 버튼 아래 계층으로 분리했다.
- 설정은 Data/Presentation/Data_Exploration_탐험.asset, 방향별 그림 데이터는 Data/Presentation/Exploration, 사건별 발견 방식과 선택 후 모습은 RandomEventData/EventOption에서 편집한다. 코드의 사건 이름 분기로 동작하지 않는다.
- 모든 추가 게임 문구는 TMP와 한국어 키/CSV를 사용한다. 소모 상태의 그림 크기는 원래 오브젝트의 폭에서 자동 계산한다.

준비 코드는 기존 디자이너의 비어 있지 않은 연결을 덮어쓰지 않는 일회성 에디터 준비이며 수동 베이크 메뉴를 요구하지 않는다. 기존 스테이징 작업은 되돌리거나 새로 스테이징하지 않았다. 변경 전 관련 자산은 Before에 보관했다.

검증: GenerationAudit.txt는 막별 64개의 일반 시드에서 구조/열쇠/필수 경로를 검사한 기록이다. Live.txt/LiveComplete.txt는 실제 열린 Unity Editor에서 변경된 상호작용만 검사한 결과다. 이 검사는 사용자의 자연스러운 전체 플레이 경험 평가를 대체하지 않는다. 전체 DPS/밸런스 비교와 실기기 테스트는 실행 범위에 포함하지 않았다.
