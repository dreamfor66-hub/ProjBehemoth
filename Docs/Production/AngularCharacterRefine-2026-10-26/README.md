# 투구 구조 · 격노 표정 수정

내장 `image_gen`의 편집 모드를 사용했다. [PromptSet.json](PromptSet.json)에 입력 역할, 프롬프트, 생성 원본 경로를 기록했다.

- 워리어: 포트레이트를 입체 구조 기준으로 삼았다. 앞판처럼 보이던 뒤쪽 리벳/삼각판을 제거하고, 비스듬한 정수리 능선과 넓은 후두부 면, 목에 맞춰 휘고 벌어지는 낮은 테두리로 바꿨다. 정면을 향한 뒷모습을 유지한다. 몸/방패/검은 새로 그리지 않고 생성된 머리 영역만 기존 이미지에 합성했다. 머리 밖 변경은 0픽셀이다([Pixel-Invariants.json](Pixel-Invariants.json)).
- 곰가죽 바바리안: 기존 인간 시안의 곰가죽·수염·체형·양손 도끼를 유지했다. 원래 리자드는 호탕한 건달 같은 성격 참고로 사용했다. 낮춘 눈썹, 드러난 눈, 올라간 입꼬리와 이빨을 보이는 포효, 앞으로 기운 비튼 상체와 팔의 힘으로 격노를 표현했다. 광원/마법 이펙트는 추가하지 않았다. 도끼의 연속된 직선 자루와 양손 그립을 확인했다. 기존 차분한 시안은 `BarbarianBearPelt01.png`, 수정 시안은 `BarbarianBearPelt02.png`로 분리한다.

## 최종 경로

- 비교 시안: `Assets/Art/Concepts/BarbarianBearPelt02.png`
- [전후·포트레이트·전체 배열 비교](Gallery.html)

## 검토

사용자 원본 두 장, 기존 포트레이트, 수정 전후 및 다른 5종과 함께 회색/어두운 배경에서 검토했다. 바바리안의 엄숙한 표정을 전투를 즐기는 포효로 바꿔 가장 큰 성격 차이를 수정했다. 굵은 외곽선과 큰 명암을 유지했고, 포트레이트의 얼굴과 로그 원본은 수정하지 않았다. 투구는 원본의 각진 면을 유지하면서 뒤에 잘못 복제된 앞판을 제거했다.

Unity의 기존 MainGameScene에서 워리어의 교체된 그림을 실제 렌더링하고 `Screenshots/Warrior-Helmet02.png`에 기록했다. 배경/선택 UX/확대값/게임 데이터와 입력 로직은 이번 수정에서 변경하지 않았다. 별도 밸런스 테스트는 실행하지 않았다.
