# 캐릭터 재디자인

## 요구사항

- [x] 워리어: 얼굴 전체를 가린 폐쇄형 투구와 판금 갑옷.
- [x] 바바리안: 근육질 리자드, 뿔·주둥이·꼬리, 도끼.
- [x] 몽크: 모든 피로도에서 눈을 가리는 안대, 큰 염주, 성숙한 체격.
- [x] 위자드: 진지한 노인 남성, 긴 백발과 수염, 주름.
- [x] 로그: 가벼운 표정과 역수 쌍단검. 공격·방어 그립도 별도 수정.
- [x] 사무라이: 동양 장발 미남과 기존 분위기 유지.
- [x] 6직업의 선택 이미지·전투 대기/공격/방어·초상화/피로도 이미지 66개 교체.
- [x] 기존 PNG 캔버스 크기, 패딩, 스프라이트 GUID와 데이터 참조 유지.
- [x] 게임용 7색, 이진 알파. 해상도를 낮추는 중간 래스터 없음.
- [x] 동일 디자인의 별도 컬러 원화 6개: `Color/`.
- [x] Unity 라이브 선택 화면·대기/공격/방어 확인: `Live.txt` 참조.

원화 생성은 Built-in image_gen 사용. 요청 및 참조 역할은 `Prompts.json`에 기록했다.
게임용 원본은 `Assets/Art/DarkSeven/CharacterRedesign/`, 실제 소비 파일은 기존 `Assets/Art/Characters/`에 있다.
원본의 미세한 색 흔들림이 색 경계에서 얼룩으로 변하지 않도록, 각 원화의 색 분포에서 비어 있는 구간을 톤 경계로 선택한다. 결과 픽셀은 항상 기존 7색 중 하나이다. 원래 전투 수치와 클래스 데이터는 변경하지 않았다.
컬러 원화는 게임용 제한 팔레트를 적용하지 않은 별도 검토용이다.

`audit.py`는 이미지를 읽기만 하며 캔버스 크기·색·알파·최신 생성 여부를 검증해 `AssetAudit.json`을 쓴다.
라이브 검증은 기존 Unity 인스턴스에서 해당 캐릭터의 선택/대기/공격/방어만 확인한다. 기기 입력·밸런스 전체 회귀는 이번 범위에 포함하지 않는다.
