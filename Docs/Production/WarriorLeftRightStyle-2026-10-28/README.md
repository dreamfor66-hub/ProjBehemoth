# L→R 워리어 원화의 고유 디자인 복원

사용자 지시: 새 L→R 원화가 기존 Idle/Guard의 색감, 망토 길이, 요철과 작은 명암 조각을 줄인 규칙에서 벗어났다. 새 두 그림을 원본 캐릭터에 맞춰 수정한다. 선택된 긴 검과 베기 자세는 유지한다.

## 변경
- Ready의 오른쪽 허리까지 내려가던 긴 망토 꼬리를 제거했다. 원본처럼 벨트 위에서 끝나는 짧은 어깨 망토로 맞췄다. 허리 아래 천과 어깨 망토를 구분한다.
- 두 그림의 잔 톱니·길쭉한 천 조각을 큰 비정형 천 끝과 넓은 허리천으로 묶었다. 첫 Attack 수정에 남은 왼쪽 어깨의 작은3연속 톱니도 추가 편집하여 한 덩어리 모서리로 정리했다.
- 밝고 노랗던 올리브/주황 가죽을 원본 Idle/Guard의 탁한 올리브·어두운 갈색·따뜻한 회색 철색에 맞췄다. 천·갑옷의 작은 조각 명암을 큰 면으로 통합했다. 목의 황토색 포인트를 유지했다.
- 오른팔/왼방패, Ready의 몸 앞에 가려진 검손, Attack의 정수 그립과 펼쳐진 팔을 유지했다. 기존 긴 칼날은 생성 과정의 미세 변화를 적용하지 않고 원래 칼날 영역 픽셀을 복원했다. Registration.json의 보존 영역 검사가 두 그림 모두 true다.
- 새 생성물을 기존2896×1304 캔버스에 등록했다. 이미지 전체를 공간 끝까지 채우거나 캐릭터 크기를 재설계하지 않았다. Unity 메타/GUID, 데이터 참조, 씬/프리팹, 입력·밸런스 코드는 바꾸지 않았다.

## 실제 검토
사용자 원본 03-armored-hood-fighter.jpg / 04-brawler-back.jpg와 현재6종 AllSix-Corrected.png를 열어 큰 명암 면, 외곽선, 색의 절제와 묘사 밀도를 확인했다. 캐릭터별 복장·색상 기준은 생성된 전투 그림이 아닌 기존 Idle/Guard다. Comparison.png / Comparison-Dark.png에서 같은 원화 배율로 원본→이전→수정 후를 회색/어두운 바탕에서 비교했다. 무광 철색, 짧은 망토와 큰 천 조각, 후면 투구/양팔 장비의 연결을 확인했다. 검수가 사용자 승인이라는 뜻은 아니다.

PaletteComparison.json은 알파>220의 대략적인 올리브 유사색을8단위로 묶은 보조 자료다. 금속/가죽 일부도 포함되므로 엄밀한 재료 분할이나 색 동일성 증명이 아니다. 원본 Idle/Guard도 밝기 차이가 있어 육안 비교를 함께 사용했다. 대표 묶음은 원본 Idle100/92/76, Guard116/108/84이며, 이전 Ready132/124/92에서 수정 Ready116/108/84로, 이전 Attack124/116/84에서 수정 Attack108/100/76으로 이동했다. 첫 후보 기준이며 Attack 후속 편집은 작은 외곽선 정리다.

## 파일과 적용
실제 적용: Assets/Art/World/Angular/States/Heroes/Warrior-Ready-LeftToRight.png 및 Warrior-Attack-LeftToRight.png.

Before/는 변경 전6자세와 대상 메타, *-Generated.png는 내장 image_gen 출력, Prompts.json은 정확한 프롬프트다. Before/After-Hashes.json에서 L→R 두 장만 바뀌고 Idle/Guard/기존 우→좌는 바이트 동일함을 확인했다. 대상 메타도 바이트 동일하다. Art/AGENTS.md와 STYLE_GUIDE.md에 새 액션을 그려도 원본 Idle/Guard의 색·망토 물리적 길이·요철/명암 밀도를 유지한다는 기준을 추가했다.

그림만 교체한 작업이다. 시스템/성장 수치 검증 및 Unity Play 검증은 수행하지 않았다.
