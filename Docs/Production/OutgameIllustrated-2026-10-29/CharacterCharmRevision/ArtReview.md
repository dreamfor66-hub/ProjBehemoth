## 스타일 비교

사용자 제공 원본 03-armored-hood-fighter.jpg와 04-brawler-back.jpg를 실제로 열어 큰 실루엣, 선택적 내부선, 큰 명암 덩어리를 비교했다. 현재 여섯 캐릭터 정면 원화와 이전 Unity 선택창도 함께 검토했다. 이전 여섯 장의 반복되는 깨진 기둥/잔돌/갈라진 바닥/잔파편 구도를 대체했다. 새 그림은 선명한 해상도를 유지하면서 배경 구조와 의상 외곽의 잔갈래, 작은 면을 줄였다. 바바리안의 근육, 곰가죽, 도끼는 1차가 특히 과하게 세분되어 해당 부위를 재정리했다. 털의 특징과 근육이 읽히는 큰 면은 남아 있으므로 무요철/무명암 스타일로 바꾼 것은 아니다.

## 실제 화면 검토

기존 Unity Editor에서 여섯 선택 버튼의 실제 콜백으로 화면을 전환하고 1920×1080 화면을 각각 캡처했다. Selection-Overview.jpg 및 각 Selection-*-Live.png를 실제로 열어 얼굴과 각 장면의 주요 행동, 상체/책/양초/검/손끝의 UI 가림과 좌측 글자 대비를 확인했다. 자동 확인 25 PASS, 0 FAIL. 단순 스프라이트 참조 확인만으로 시각 통과를 판단하지 않았다.

원화/버튼/전투 PNG와 제목 로고/타이틀 배경은 이번에 교체하지 않았다. 여섯 선택창 PNG만 같은 경로에 대체하여 메타 GUID를 유지했다. 새 아트 규칙은 root AGENTS.md, Assets/Art/AGENTS.md, AngularCharacterStyle/STYLE_GUIDE.md에 프로젝트 전체의 이후 작업에도 적용하도록 기록했다.
