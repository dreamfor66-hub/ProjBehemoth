# 바바리안 후면 팔 연결09

변경 자산은 `Assets/Art/World/Angular/Heroes/Barbarian-Rear.png` 한 개다. 현재 채택 파일은 이 폴더의 [Barbarian-Rear09.png](Barbarian-Rear09.png)와 동일하다.

왼손을 몸 왼쪽에 배치해 가려진 팔이 반대편 허리까지 가로질러야 하는 구조를 제거했다. 양쪽 상완/팔꿈치/전완/손목을 직접 확인할 수 있는 준비 자세이며, 팔을 도끼에 맞춰 늘리지 않고 양손 그립과 도끼 방향을 함께 조정했다. 곰가죽/허리 위 구도/승인 앞모습과 원본의 굵은 선·넓은 명암을 기준으로 대조했다.

내장 `image_gen`으로 수정. [생성 및 후속 소품 정렬 프롬프트](FinalPromptSet.json).09에서 팔 연결을 먼저 수정하고09c/09d에서 자루/소켓 정렬을 다시 수정했다. 무기 축 보조선은 생성 입력일 뿐 최종 이미지에 포함되지 않는다. `ApplyRear09.ps1`는 투명영역 및 하단 노이즈 정리 후 후면 한 파일만 복사한다.

## 검증

- 원본 레퍼런스2장, 승인 앞모습, 전후면 확대 및 회색/어두운6종 배열과 육안 비교.
- 양쪽 손을 각자의 몸 옆에 놓아 팔의 연결과 굽힘을 대조. 전완은 보는 각도에 따른 단축이 있으므로 화면상의 길이를 같게 늘리지 않았다.
- 기존 Unity Editor의 실제 Play 모드에서 바바리안 후면을 확인/캡처했다. [실제 전투 화면](Screenshots/Combat-Barbarian09.png). 검증 후 MainGameScene Edit 상태 복귀.
- [다른 캐릭터/앞모습 파일 유지 검사](Applied-Check.json). 게임 UX·배경/캐릭터 배율·수치 변경 없음. 밸런스/전체 회귀 검증은 실행하지 않았다.
- 기존 전체 비교판 `AngularRebuild08-2026-10-26/Gallery.html`도 후면09와 이번 전투 캡처로 갱신했다.
