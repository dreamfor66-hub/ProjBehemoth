검사된 모든 텍스트의 주 폰트가 YiSunShin으로 일치하고 누락 글리프가 없다.
이벤트 페이지 버튼의 30px 높이 텍스트 상자에서 새 폰트가 잘려, 기존 버튼 안쪽을 채우도록 저장 레이아웃을 보정했다.
전투 숫자의 기존 42px 높이도 80px로 보정했다. 최종 이벤트·전투 숫자 감사에서 overflow=True가 없다.
각 txt에는 라벨별 폰트, 크기, 넘침, 누락 글리프와 표시 문구가 기록되어 있다.

## 확인 범위

현재 검증은 대표 화면과 변경된 표시 동작에 한정된다. 모든 이벤트/직업/해상도 조합,
실제 모바일 기기 및 전체 플레이의 장시간 독해 평가는 아직 수행하지 않았다.
전투 밸런스/물리/입력 로직 변경은 없으며 전체 DPS/회귀 검증은 실행하지 않았다.
숫자 검증은 표시 생성 경로 검증이며 새 전투를 진행한 밸런스 플레이테스트가 아니다.
