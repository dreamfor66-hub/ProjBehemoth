# 중단 이후 누락 재점검 · 2026-10-27

## 발견한 누락

훈련 인형 TrainingLight / TrainingMedium / TrainingHeavy 3종이 이번 2D 교체 및 실행 검증 목록에서 빠져 있었다. 세 데이터는 기존 픽셀 훈련 인형의 Idle / Ready / Attack / Dead 4장을 공유한다. 4개 상태의 실제 연결은 정상이며, 이번 2D 전환은 미완료 상태다. 이번 점검에서는 새 아트를 생성하거나 게임 데이터를 변경하지 않았다.

앞서 보고한 48개 완료는 캐릭터 6종 + 일반·엘리트·보스·동행/소환 몬스터 41종 + 동행견 1종에 해당한다. 프로젝트에는 훈련 인형을 포함해 MonsterData 44개가 있다.

## 누락이 없었던 항목

- 위 48개 개체의 184개 상태 슬롯을 실제 GUID와 PNG 경로까지 대조했다. 빈 슬롯, 잘못된 연결, 원본과 반영본의 불일치가 없다.
- 승인·설치·최신 실행 검증 기록을 현재 파일의 해시와 대조했다. 48개 모두 일치한다.
- 새 이미지 137장 모두 정상 PNG·투명 배경·규격에 맞는 비율을 확인했다.
- 기존 승인 Idle 47장과 전투 수치·공격 시간·위치·크기 설정이 보존되어 있다.
- 생성 중 거절됐던 결정 성게 Dead와 폭풍의 대붕 Ready는 최종 수정본이 실제로 설치·검증되어 있다. Error.json은 초기 실패 이력이다.
- 갤러리의 이미지 파일 누락은 없다.
- GameContent에서 선택 가능한 캐릭터 6종은 교체 목록과 정확히 일치한다. 별도의 Angular01 시험용 캐릭터 자산 6개는 현재 선택 목록에 포함되지 않는다.
- 초기 실인형·폭풍 해파리 검증 실패는 이후 통과 로그로 해결되어 있다.

## 기록 정정

FinalPromptSet.json의 135개 항목에 남아 있던 초기 generated_pending_review 표기를 최종 설치·검증 완료로 수정하고, output도 실제 Assets 저장 경로로 바로잡았다. 게임 이미지나 연결의 결함이 아니라 최종 기록의 낡은 값이었다.

근거: CompletenessCheck.json, Audit.json, 최신 개체별 Live 로그 및 Approved/Installed/Verified 기록. 기존 실행 검증 기록을 대조했으며 이번 재점검에서 전체 게임 테스트를 반복하지 않았다.
