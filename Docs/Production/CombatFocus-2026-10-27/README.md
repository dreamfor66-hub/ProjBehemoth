## 검증 범위

기존 Unity Editor 한 인스턴스에서 명시적으로 실행하는 CombatFocusVerification/CombatFocusLiveProbe. 승리/패배/초기화, 시작 및 복귀, 정지 시간 배율, 실제 입력 경로의 가드/해제, 공격/쿨다운, 1/2/3마리 위치 유지, 공통 전환의 다른 클래스 1종만 확인한다. 테스트 몬스터와 예시 2/3마리 encounter는 런타임 복제본이며 저장하지 않는다. 별도 Unity, DPS 비교, 전체 회귀 테스트는 실행하지 않는다.

첫 실행에서 Root/확대/복귀는 통과했으나, 화면 아래에 위치한 가드 기준점 때문에 드래그 가드가 불가능한 문제가 드러났다. GetPlayerBodyShape를 보이는 논리 화면 영역으로 잘라 가드가 가능한 중심점으로 수정했다. 첫 다중 몬스터 판정에는 프레임 말에 삭제될 이전 뷰가 포함되어 테스트 비교를 수정했다. 두 번째 실행은 진단 코드의 Unity null Sprite 이름 접근 오류로 중단되었으며 진단 코드를 고쳤다. 최종 재검증 결과는 Live.txt에 기록한다.

실제 모바일 기기의 터치감 및 해상도별 육안 검토는 미실시. 전투 수치/AI/보상/장비 데이터 변경 없음.

최종 드래그 좌표는 실제 화면 안에 있는 시작/종료점인지 별도로 검증했다. 가드 한 손 유지 + 다른 손 공격/해제, 반대로 두 번째 접촉 유지 + 가드 손 해제/재입력을 세 번 반복했다. 접촉을 모두 취소하는 초기화는 사이에 호출하지 않았다. 공격은 기존 입력 설계대로 횡단 확정 또는 손을 뗄 때 실행되며, 겹침 검증의 첫 버전은 손을 떼기 전에 쿨다운을 확인하던 테스트 오류를 수정했다. 최종 두 입력 로그 모두 failures=0. 마지막 검증 후 Play 종료, 워리어 선택 상태.

화면의 기존 회색 세로 요소는 PlayerShieldBar의 SlantedGuardGauge이며 원화/스프라이트 오류가 아니다. 이번 작업에서 기존 게이지의 위치/디자인은 변경하지 않았다.
