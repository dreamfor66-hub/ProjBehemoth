# 이번 작업의 완료 기준

- [x] 1~3막 전체 이벤트의 최초 발견, 선택, 종료, 재방문을 실제 보이는 대상과 일치시킨다. 특정 방·시설에 들어갔다는 가정은 우연히 만나는 인물·이동 가능한 사물로 윤문한다. 비활성 사건도 검토하되 보상/조건을 임의로 바꾸지 않는다.
- [x] 활성 이벤트마다 고유한 최초 상호작용 그림을 사용한다. 상인·비밀문 단서·일반 상자와도 공유하지 않는다. 미지정 그림으로 공유 fallback을 노출하지 않는다.
- [x] 상인은 얼굴을 그늘에 가린 수상한 후드 인물로 교체한다. 프로젝트의 큰 먹선·단순한 면·실제 배경 투시를 준수한다.
- [x] 같은 층의 상인/여신상/분수(독 분수 포함)는 같은 계열끼리 최소 4칸의 이동 거리를 둔다. 부족하면 그래프를 다시 생성한다.
- [x] NPC와 동물은 실제 첫 진입 방향에서 얼굴이 보이는 위치·방향을 정하고, 이후 재방문에는 세계 좌표를 유지한다. 구조물 배치는 유지한다.
- [x] 야영은 입구 하나의 막다른 방 전체로 표현하고 별도 자원은 추가하지 않는다.
- [x] F1에 모든 활성 사건의 고유 오브젝트를 연결한다. 세 막의 실제 Unity 화면과 상호작용/재방문/배치/생성 규칙을 검수한다.

컴퓨터 직접 조작은 제작 완료 뒤에만 사용한다. 연결된 도구가 없으면 기존 Unity 한 개의 런타임에서 UI 레이캐스트/입력 핸들러와 캡처를 사용하고 물리 입력 검수의 한계를 기록한다. 전투 밸런스 비교는 범위에 포함하지 않는다.
