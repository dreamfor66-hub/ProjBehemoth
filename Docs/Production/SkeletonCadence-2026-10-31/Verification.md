# 해골 전사 공격 순서 복원

- [x] 약공격 2회 → 강공격 1회 반복.
- [x] 해골 전사 데이터의 `chargeInterval`만 4 → 5초로 변경. 약공격 간격 2초 유지.
- [x] 고블린 사냥꾼 데이터와 기존 공격 피해량/준비 시간 유지.
- [x] 기존 Unity Editor Play 모드에서 실제 CombatController로 첫 순서, 다음 반복, 기절 회복 후 순서 확인. 모두 약→약→강 통과.

원인: Idle 중 두 타이머가 함께 감소하고 강공격이 우선된다. 기존 강공격 간격 4초는 약공격 간격 2초의 정확히 두 배여서 두 번째 약공격 대신 강공격이 시작됐다. 5초로 변경하면 두 번째 약공격 이후 강공격으로 이어진다.

실행 결과와 시각은 `Live.txt`에 기록했다. 검증 중 플레이어 체력만 회복시켰고 적 데이터와 타이밍은 저장된 원본을 사용했다. 두 번째 강공격 준비 중 기절을 주입해 회복 이후 순서를 추가 확인했다. 검사 후 Play 모드를 종료하고 임시 검증 코드는 이 문서 폴더로 보관했다. 범위 밖 밸런스/DPS 비교는 실행하지 않았다.
