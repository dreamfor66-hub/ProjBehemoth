검수 과정에서 에디터 전용 QA 컴포넌트의 어셈블리 위치와 선택 씬에서 QA를 호출한 설정 오류를 수정했다. `Logs/AshenVow-Errors.txt`에는 이 과거 기록이 남아 있다. 이후 정상 MainGameScene에서 수행한 위 행렬은 통과했다.

## 검수 범위의 한계

- 두 접촉 입력은 실제 입력 컨트롤러에 Begin/Move/End를 전달하고 프레임을 진행해 확인했다. 물리 터치 기기의 장시간 양손 조작은 별도 기기 검수 대상이다.
- 새 조합의 장기 난이도·전 직업 DPS 비교는 미실행이다. 사용자 지시에 따라 전체 밸런스/회귀 스위트를 추가 실행하지 않았다.
- 20개 성 내부 사건의 데이터/문단 구조는 검사했고, 플레이 분기 검수는 변경 핵심인 마법선생과 개 사건에 집중했다.
