# 사건 전수 재설계와 반려 기록

기준은 기존 선택지 보존이 아니라 **보이는 대상 → 관찰 가능한 정보 → 그 행위의 비용/결과 → 같은 공간에 다시 왔을 때의 상태**가 연결되는가이다. 기존 19개를 모두 읽고 그중 `Contract`는 재수정안까지 반려해 일반 풀에서 제외했다. 최종 활성 사건은 18개다. 기본 이벤트 방 수는 이 수와 별개로 유지된다.

## 참고한 실제 자료와 적용 범위

- [D&D Basic Rules: Adventuring](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/adventuring): 환경 제시, 플레이어 행동, 결과의 순서와 물체를 조작하거나 부수는 탐험 행위를 확인했다. 여기서 가져온 것은 지각 가능한 단서와 행동의 인과다. D&D가 모든 정보나 성공 확률을 공개하도록 규정한다는 주장은 하지 않는다.
- [Wizardry Archives 원 게임 매뉴얼](https://wizardryarchives.com/downloads/archivesmanual.pdf)의 Proving Grounds of the Mad Overlord 인쇄 42쪽(PDF 40쪽): 직접 다운로드한 원 매뉴얼에서 열기·육안 조사·주문 조사·해체·포기의 별도 행동을 확인했다. 상자가 던전에 있다는 것 자체는 억지가 아니며, 플레이어가 알지 못한 설치자·함정 내용을 서술자가 안다고 단정하는 것이 문제다. 원문 PDF는 프로젝트에 배포하지 않고 로컬 조사 캐시에만 보관한다.
- [Chris Bourassa의 Darkest Dungeon 개발 인터뷰](https://80.lv/articles/red-hook-studios-talks-about-the-creation-of-darkest-dungeon): 불완전한 정보로 영구적인 결정을 내리는 탐험과 인간의 취약함, 큰 검은 덩어리와 그림의 무게에 대한 개발자 설명을 확인했다. 모든 소품을 마법으로 소멸시키거나 모든 사람이 절망한 자세여야 한다는 뜻으로 해석하지 않았다.

아래는 이 자료에 대한 **제작 판단**이다. 세 작품의 공식 사건 설정을 복사하거나 그 감성을 객관적인 체크 점수 하나로 확정했다는 주장이 아니다. 실제 설치 화면의 투시·접지·명도·선 밀도 합격은 루트의 Unity 검수 기록과 별개로 남긴다.

## 반복 검토에서 버린 판단

1. 1차안은 정적인 사물 대부분에 재오픈을 주었다. 사용자가 요구한 일회 사건의 종결을 회피한다고 판단해 반려했다. 일반 시설 취소와 미해결 생물 조우에만 보류 프리미티브를 사용한다.
2. 금고의 소액 주머니와 큰 저주 금고는 물리적으로 선택이 갈릴 이유가 없었다. 주머니·저주 원형을 버리고 실제 붕괴 위험으로 바꿨다.
3. 책과 계약서를 모두 손목에 붙였다가 파기하게 만드는 2차안은 같은 장면 반복이었다. `Contract`는 이 수정안도 보존만 하고 일반 추첨에서 제외했다. 기존 거울/쇠덫을 복귀시키지도 않는다.
4. 배달 보상에 원래 +45G를 남긴 것은 운송인의 직업 논리를 깨뜨렸다. 타인의 잔금과 장비선택 잔재를 지우고, 포장된 장비 하나를 실제 하나 지급한다.
5. 보상이 없고 비용이 없다는 이유만으로 모든 선택을 보류 처리하면 마력 위협 같은 실제 행동까지 취소된다. 도적 위협은 반응·퇴장으로 종결하고, 단순 보류만 명시적 데이터 플래그로 남겼다.
6. 강화를 연속 두 번 지급하면 첫 강화로 마지막 가능 스택을 소모한 뒤 빈 선택 창이 남을 수 있었다. 검정 보상을 강화1로 정리하고, 범용 효과 처리에도 후보가 없으면 다음 단계로 진행하는 방어를 추가했다.

## 실제 검증에서 확인할 것

- 미해결 NPC의 보류 뒤 앞/뒤 재접근과 실제 적대 결과, 해결 뒤 재보상 없음.
- 금고 양쪽 결론에서 같은 코너의 빈 배수구가 남는지, 방향이 바뀌어도 틈이 이동하지 않는지, 플레이 코드가 후행 자산을 복원하는지.
- 혈근 세 선택의 고갈 그림과 내레이션, 고기/포션의 실제 소비, 회수견 합류.
- 교범 파기·독서 뒤 빈 독서대 유지, 훈련 긴급정지와 세 전투 보상의 실제 소진, 예약 장비의 단일 지급.
- 회수인/행상의 발화가 실제 그림의 표정·소지품·직업과 맞는지. 그림을 바꾼 네 사건은 세 막의 실제 크기와 명도에서 재검수한다.

정적 문서/합성 보드 통과를 플레이 완료로 간주하지 않는다. 최종 Unity 런타임 검증 및 실제 화면 승인 결과는 루트 검수 기록을 기준으로 한다.

## 교범 종결 아트의 추가 수정과 반려

루트가 실제 원화를 다시 열어, 교범 그림에 석조 독서대도 포함되었음을 확인했다. 기존 `removeWorldObject`는 책뿐 아니라 독서대까지 없애므로 종결 그림이 부적절했다. 원본 Front/Side/Rear를 각각 편집해 책과 종이만 제거한 빈 독서대 3장을 추가했다. 모든 종결을 `useWorldObject=true`, `removeWorldObject=false`, 교체 자산 없음으로 수정했고, 책은 사라지고 빈 독서대가 남았다는 재방문 문구를 사용한다. 현재 ArtReady는 총25개 독립 PNG를 가리킨다.

세 used 그림은 원본과 같은1374×1145 캔버스다. Front의 실제 석재 영역(y≥800, alpha≥180)은 원본 x37~1335, used x42~1329로 폭 차이0.85%다. 반면 자동 접지 폭은1120→1239픽셀로 잡혔다. 책이 사라지면서 전체 높이의22%를 검사하던 접지 밴드와 명도55 기준이 달라진 결과이며, 실제 독서대가9.6% 커진 것이 아니다.

이 구분 전 접지 수치를 맞추려고 하부 우측의 검은 면을 바꾼 두 출력은 반려했다. 원본 하부와의 RGB 평균 차이가 최초12.31에서17.07,19.76으로 커져 원화를 오히려 손상시켰다. 별도의 재편집 시도도 설치하지 않았다. 반려 원문과 정확한 프롬프트는 `Prompts/bookUsedFront*Rejected.json`에 기록했고 생산 그림은 최초3면을 유지한다. 루트는 동일 캔버스·피벗의 normal/used에 원본 접지와 픽셀 배율을 함께 유지하는 공통 렌더링 규칙으로 이 문제를 해결했다. 새로운 수동 보정값은 만들지 않았다. 실제 화면 검수는 루트의 최종 런타임 기록을 따른다.
