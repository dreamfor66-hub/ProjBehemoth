# 1–3막 탐험·사건·아트 개편

## 반영한 경험

- 한 차례 무시했거나 아직 대화하지 않은 인물의 뒤로 접근하면 기습/대화 선택이 나온다. 인물별 대응은 독립 NpcApproachData다. 일반 상인은 반격하고 달아나며, 드문 위장 상인만 실제 다른 전투로 이어진다.
- 상점은 포션3·퍽3·유물4, 총10개다. 취소해도 남고, 구매한 뒤 실제로 방을 떠난 다음 돌아와야 떠난 상태가 된다. 구매 직후 같은 방문 중에는 추가 구매할 수 있다.
- 기존 사건19개를 전수 검토했다. 억지 수정을 유지하던 계약은 일반 풀에서 제외해 활성18개로 정리했다. 급료고·혈근·봉인 교범 등은 전제와 행위를 다시 만들고 실제 결말 그림을 붙였다. 예전 거울·덫을 복귀시키지 않았다.
- 사물 사건5종 모두 1–3막의 전용 공간을 사용한다. 평범한 방에도 경비실·서약실 변주를 추가했고, 같은 방은 재진입해도 장식이 재추첨되지 않는다. 벽 장식은 고정 세계 방향을 따른다.
- 사물 사건의 거절/중지는 붕괴·수축·교범 소진·기계 정지 등으로 해당 기회가 끝난다. 미해결 사람/생물의 보류는 다시 접근할 수 있다. 이미 조사한 자동 사건의 재입장 강제 팝업도 수정했다.
- 피로도는 실제 지도 연결·왕복·잠긴 가지로 돌아가는 이동을 계산해 부족한 경우만 최대치를 올린다. 최소100, 10단위 올림이며 현재72지도 표본은100–150이다. 캠프가 있어야 한 번의 유한 탐색을 마칠 수 있는 전제로 잡지 않았다.

## 아트 범위와 판정

생산 PNG97개를 교정/추가했다. 환경·상자·분수27, 사건/후행25, 전투 몬스터7종38, 위자드7이다. 일반 PNG와 기존 GUID/Native Sprite geometry를 보존한다. 전체 게임을 조사했지만 모든 기존 그림을 재제작했다고 주장하지 않는다. 승인된 워리어 검/팔/자세·로그 얼굴·사무라이 디자인을 지켰고 다른5직업37개 활성 PNG는 최초 해시와 같다.

정면·측면·후면 상자는 원화와 실제 화면을 반복 대조했다. 첫 런타임에서 발견한 하부 박스 변형은 반려하고 다시 제작했다. 최종14:18 화면10장을 독립 검수해 하부·바닥선·철띠 유지와 후광/버튼 인상 해소를 확인했다. 분수는 실제 탁한 물과 무광 석재이며 사용 뒤 물이 사라진다. 확대 투명 바탕의 미세한 외곽 알파까지 완전히 제거했다고 쓰지 않는다. 가까운 후면 구도의 일부 화면 잘림은 남지만 접지·조사 영역은 유지된다.

사용자의 다키스트 던전 참고와 비교한 기준은 큰 먹 면, 절제된 재질, 명확한 동작과 생존 분위기다. 단순히 어둡게 하거나 화면 전체에 노이즈/균열을 추가하지 않았다. 자세별로 독립 그림을 유지하며 회전/찌그러뜨리기로 대체하지 않았다.

정확한 생산 경로와 해시: `SavedAssets.md`, `InstalledArtManifest.json`. 시도·반려 근거: `RootArtReview.md`, `ChestCorrection/Review.md`, `CombatMood/`, `../EncounterReconstruction-2026-11-01/Review.md`. 아웃게임8장 실제 판정: `OutgameVisualReview.md`.

이 과정에서 납골당의 종의 왼쪽 약점 한 점을 실제 들어 올린 손 위로 옮겼다. 개수·반경·필요 타수·노출 시간·공격 수치는 유지했다. 실제 무리의 소형 실인형 Ready/Attack은 기존 기술명 띠가 상체를 가리는 제약이 남아 있다. 전체 그림이 항상 UI에 가리지 않는다고 주장하지 않으며, 상세 판정은 `CombatMood/NativePoseRuntimeReview.md`에 기록했다.

범위는 바뀐 기능과 직접 관련된 상호작용이다. 새 Unity 인스턴스·전체 DPS/밸런스 회귀는 실행하지 않았다. 이 검증은 사용자의 자연스러운 다섯 판에서 느낄 반복감·리스크/보상 균형·전체 난이도 평가를 대신하지 않는다. 원본/작업 중 파일과 사용자 기존 스테이징은 유지하며 커밋하지 않았다.
