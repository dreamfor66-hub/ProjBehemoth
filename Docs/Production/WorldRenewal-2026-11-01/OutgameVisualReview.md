# 아웃게임 실제 화면 판정

2026-11-01. 저장된 OutGameScene을 사용한 단일 Unity Editor의 실제 Canvas/EventSystem 검증에서 38항목이 통과했다. 타이틀, 옵션, 여섯 직업 선택의 8장 모두 root가 직접 열어 확인했다. `OutgameRuntimeReview.txt`, `Screens/Final-Outgame-*.jpg`가 실행 근거다. 이 검증은 설정을 변경하거나 새 런을 시작하지 않았다.

- 타이틀은 큰 석조 구조와 검은 음영, 제한된 불꽃이 유지되고 메뉴와 그림의 위계가 분명하다. 기존 로고의 입체감을 새로 고쳤다고 주장하지 않는다.
- 옵션 가장자리에 이전 픽셀 미궁이 노출되지 않는다. 실제 공통 잉크 배경이 연결되며, 옵션 글자와 버튼은 충분히 읽힌다.
- 위자드는 실제 선택창에서 새 PNG가 보이고, 얼굴·책·작은 부엉이와 별도 촛불이 잘리지 않는다. 작은 눈과 넓은 남청/검은 옷의 면이 다른 다섯 직업의 선 무게와 연결된다. 서재의 온기와 온화한 학자 성격은 유지한다.
- 워리어·로그·바바리안·사무라이·몽크의 기존 승인된 얼굴·자세·장비는 바뀌지 않았다. 일러스트에 어울리는 야영/야외/정원/수련장 배경을 미궁으로 강제 교체하지 않았다. 사무라이 선택 배경의 비·반사와 바바리안/몽크의 밝은 피부는 현재 그림의 개성으로 남아 있으며 모든 그림을 재도색했다고 쓰지 않는다.
- 실제 6직업 버튼, 강조 테두리, 제목·선택 그림 바인딩, 뒤로가기와 타이틀 복귀를 EventSystem으로 확인했다. UI 버튼의 잉크 테두리와 별개로, 환경에 놓인 사물이 버튼처럼 보이는지의 판정은 World/Combat 검수에 남긴다.

검증 뒤 Play mode를 종료하고 원래 MainGameScene으로 돌아왔다. 입력 모듈·클립보드·사건 기록·선택 캐릭터는 공통 probe의 복원 경로를 사용한다. 실제 사용자 다섯 판의 분위기/반복감 평가는 이 정지 화면 검증으로 대신하지 않는다.
