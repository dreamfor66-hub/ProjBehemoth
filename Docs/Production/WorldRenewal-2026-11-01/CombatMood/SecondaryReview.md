# 전투 몬스터 4종의 분위기 교정

내장 imagegen으로 기존 독립 자세 17장을 각각 편집했다. 각 호출은 해당 자세의 실제 원본, 설치된 B1 벽, 사용자가 제공한 다키스트 던전 조련사, EV GANIN 원본 해골 말 이미지를 함께 입력했다. 새 Idle은 후속 자세의 색/얼굴 일치 참고로만 사용했고 자세를 복사하거나 변형하지 않았다. 전투 수치·종별 크기·약점 데이터·프레이밍 규칙은 변경하지 않았다.

|종|교정|자세|
|---|---|---|
|실인형|반짝이는 동공을 빈 비대칭 안와로, 귀여운 봉합 미소를 날카로운 턱으로, 후드/턱/손안에 큰 블랙 덩어리|Idle, Ready, Attack, Dead, Stunned|
|종토끼|작고 깊은 눈, 마른 각진 얼굴, 검은 턱/목/복부, 무광의 종; 기존 귀·종·발·손 자세 보존|Idle, Ready, Attack, Dead|
|공허의 눈|둥근 흰 반사점과 분홍 광택 제거, 탁한 홍채, 불규칙한 검은 구강과 긴 엄니, 눈자루 밑의 검은 면|Idle, Ready, Attack, Dead|
|숯불 도롱뇽|작은 잿불 눈, 두꺼운 검은 눈두덩/턱/배/판갑 아래, 장난감 같은 금색 배를 탁한 황토로; 등판/꼬리/발 보존|Idle, Ready, Attack, Dead|

네 Portrait는 새 Idle의 실제 얼굴을 크롭한 별도 PNG로 교체했다. 생산 자산은 원래 경로에 독립 PNG 21장이다. 원화 크기가 다를 때 전체 캔버스를 비례 축소하고 투명 여백만 맞췄다. 원화에 색보정·노이즈·먹선·알파 추출 등의 코드 편집은 하지 않았다. Native Sprite 래퍼와 모든 기존 메타 55개는 SHA256이 설치 전후 동일하다. 원본은 `../Before/Assets/Art/`에 보존했다. `SecondaryInstallation.json`, `SecondaryPreservedGeometry.json` 참조.

검수는 생성 그림 전체 크기 → 같은 자세 전후 비교판 → 설치된 PNG와 실제 B1 배경을 합성한 축소 비교판 순서로 반복했다. 합성판은 아트 비교용이며 실제 런타임 구도/스케일 검증으로 주장하지 않는다. 최종 Unity 화면은 root의 단일 라이브 검사에서 확인한다.

초안 중 종토끼의 잘게 늘어난 털 명암, 공허의 눈의 돌 같은 홍채, 도롱뇽의 표면 얼룩을 거부하고 넓고 조용한 면으로 다시 그렸다. 종토끼 사망 자세의 밝은 눈동자가 남은 것도 확대 검수에서 거부하고 두 눈이 완전히 감긴 그림으로 재수정했다. 거부 이력은 `SecondaryGenerationReview.json`; 최종 선택은 `../MonsterSelection.json`, 전체 프롬프트는 `../Prompts/Monsters/`다.

자산 검증과 비교판은 완료. Unity import/실제 전투 프레임·약점 위치 대조는 root 검사 대기다. 별도 Unity 실행이나 refresh 요청은 보내지 않았다.
