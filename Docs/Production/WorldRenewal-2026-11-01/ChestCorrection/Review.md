# 상자 상태 연속성 후속 교정

1차 실제 Unity 화면에서 정면/측면 상자를 열 때 하부 박스가 바뀌는 결함을 독립 검수와 root가 함께 발견했다. 같은 캔버스·피벗·화면 Rect를 유지하는 것만으로 원화 내부 모서리의 일치를 증명할 수 없었다.

닫힌 각 방향 PNG를 기준으로 덮개만 여는 imagegen 편집을 시행했다. 첫 측면/후면은 하부 폭·판자/철띠 위치가 달라 반려했다. 외곽만 고치려던 정면2는 작은 광점까지 생겨 반려했다. 최종 **Front1 / Side3 / Rear3**의 실제 전체 그림과 비교판3장을 root가 직접 열어 선택했다. 정면은 하부 x119..1477/y940(기준 x121..1478/y939), 측면 x133..1447/y1001(기준 x133..1447/y1000), 후면 x121..1451/y961(기준 x120..1457/y957)이다. 수치는 y>=600의 실제 재료 알파 영역에 대한 위치 검증이며 단독 미술 합격 점수가 아니다. 하부 판재·철띠·잠금판/경첩의 상대 위치도 함께 확인했다.

정면1·측면3·후면3을 byte-exact로 생산 Used PNG에 복사했다. 1536×1024 캔버스와 기존 메타/GUID를 유지했으며, 코드로 명도/색/윤곽/알파를 가공하지 않았다. 직전 생산 Used 그림은 `../Before/ChestStateCorrection/`에 보존했다. 선택 원문·설치 SHA256은 `Selected.json`, 전체 시도·프롬프트는 `Candidates.json`, `Prompts/`다.

원본 닫힌 그림과 생성 결과 모두 확대 투명 바탕에서 매우 옅은 외곽 알파가 보인다. 이를 없앴다고 주장하지 않는다. 배경에 놓았을 때 독립 발광/후광으로 읽히는지는 실제 게임 크기에서 별도로 판정하며, 하부 일치 문제를 해결했다는 이유만으로 환경 조화까지 자동 합격시키지 않는다. 최종 Unity 설치 후 화면 판정은 WorldRenewal 최종 검수 기록에 남긴다.

14:18 실제 Unity10장(1막6상태/시점, 2·3막 정면 전후4장)을 root와 독립 검수자가 열어 확인했다. 하부 박스·철띠·바닥선이 유지되며, 외곽 알파가 배경에서 발광/후광 또는 밝은 버튼 테두리로 읽히지 않는다고 판정했다. 전후 캔버스/지원점/픽셀 크기 검사도 통과했다. 가까운 후면 구도의 오른쪽 일부 잘림은 남지만 접지와 클릭 가능한 면적을 유지한다. `../IndependentWorldArtReview.md` 참조.
