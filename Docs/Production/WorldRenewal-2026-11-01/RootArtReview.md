# 환경·전투·플레이어 원화 교정

판정 기준은 어둡게 보이는가가 아니라, 실제 설치된 방과 인물의 큰 형태·먹 덩어리·재질·카메라에 맞는가이다. 생성 프롬프트에는 설치 원본과 프로젝트 배경을 직접 입력했다. 사용자의 다키스트 던전 자료는 큰 검은 면과 재질의 무게를 대조하는 자료로 사용했다. 다른 게임의 캐릭터나 장소를 복제하지 않았다.

## 환경

- 보물상자: 광택 띠와 장식적인 자물쇠, 반복되는 작은 균열을 줄이고 무광 철과 큰 목재 면으로 교정했다. 닫힘/열림 및 정면/측면/후면을 독립 PNG로 유지했다. 방향별 자물쇠 판의 불일치를 나란히 검수한 후 국소 재수정했다.
- 분수: 작은 돌 균열·백색/청록 광택을 줄이고, 검은 대접 하부·조용한 석재 면·가느다란 탁한 물줄기로 다시 그렸다. 사용 후에는 실제 물과 물줄기가 없는 상태다.
- 평범한 방: 옛 경비실 3막 그림과 잊힌 서약실을 추가했다. 기본 방을 포함해 시드/방 ID로 고정 선택한다. 특별한 사건이 없는 방의 건축 차이다. 같은 방에 다시 들어온다고 재추첨하지 않는다.
- 방향: 기본 건축은 사방 반복 가능한 구조로 그렸다. 비대칭 천과 돌 문장은 고정된 방의 벽에 붙이고 실제 원근 평면으로 투영한다. 문이 있는 벽에는 표시하지 않는다. 오른쪽 벽에서 문양을 거울상으로 뒤집던 초안은 독립 코드 검수 후 고쳤다.
- 사물 사건: 폐성 급료고·혈근 번식실·물자 보관칸은 3막별 그림을 제작했다. 기존 기록실과 사용자가 긍정적으로 본 훈련 보관실을 별도 테마 데이터로 연결했다. 금고 아래 붕괴부와 후행 배수구는 배경에 굽지 않고 같은 위치에서 바뀌는 독립 오브젝트다.

모든 새 방은 기존 1막 카메라와 바닥 높이/소실점/문 오버레이 위치를 기준으로 그렸다. 막별 조명을 다시 그려 2막에 노란 불꽃이 남는 공용 배경을 설치하지 않았다. 공유 서약실은 불꽃 없는 중립 그림으로 공통 조명을 적용한다. 방 테마와 그림은 `Assets/Data/Presentation/RoomThemes`에서 편집한다.

## 전투와 게임 바깥 화면

- 몬스터 7종: 고블린 사냥꾼·납골당의 종·철니 미믹·실인형·종토끼·공허의 눈·숯불 도롱뇽. 큰 반짝임·익살스러운 눈/혀·장난감 재질을 교정했다. 기존 개별 자세를 다시 그렸으며 회전·찌그러뜨리기 등의 절차적 움직임은 추가하지 않았다. 능력·공격 수치·종별 크기는 그대로다. 최종 런타임에서 납골당의 종의 왼쪽 약점 한 점만 실제 들어 올린 손 위로 옮겼다. 약점 수·반경·필요 타수·노출 시간·공격력은 유지했다. 다른 막의 약점과 전투 튜닝은 변경하지 않았다.
- 실제 활성 6직업과 타이틀을 추적했다. 미사용 리자드 바바리안이나 옛 로고를 현재 화면으로 오인하지 않았다. 워리어의 검/팔/자세, 로그 얼굴과 사무라이의 승인 디자인을 보존한다.
- 위자드 7개 활성 그림은 전수 검수에서 지적한 큰 눈과 동화적 재질을 교정해 설치했다. 노학자·부엉이·책·촛불과 기존 네 자세는 유지한다. 실제 설치/검수 결과는 `CombatMood`의 플레이어 기록과 최종 런타임 기록을 기준으로 한다.
- 옵션에서 노출될 수 있는 공통 픽셀 배경은 기존의 실제 잉크 타이틀 배경으로 연결한다. 아웃게임의 타이틀/옵션/6직업 선택은 별도 실제 Canvas 검수 대상이다.

## 실제 반려 및 보존

상자 초안의 표면 입자·일괄 굵은 외곽선, 혈근 방 초안의 여러 붉은 포낭과 잔가지, 전투 초안의 털/금속 잔무늬를 반려했다. 하나의 포낭만 실제 조작 대상으로 남기기 위해 배경의 포낭을 제거했다. 자물쇠 수정 중 닫힌 상자를 열린 상태로 바꾼 출력도 사용하지 않았다. 국소 수정의 마지막 선택 원본은 `ArtReady.json.correctionSource`에 기록한다.

생산 원화는 일반 PNG다. 기존 PNG 메타/GUID 및 Native Sprite의 픽셀 영역·피벗·PPU를 보존했다. 생성 크기가 다를 경우 원본 캔버스로 비례 배치하는 정적인 여백 보상만 했다. 원화에 코드로 음영·노이즈·선·색보정을 덧씌우지 않았다. 이전 파일은 `Before`와 사건 제작의 `BeforeAssets`에 보관한다.

생성 원본·프롬프트: `GenerationManifest.json`, `CofferCorrectionPrompts.json`(반려), `CofferLockPrompts.json`, 각 제작 하위 폴더. 생산 경로: `RootAssetFiles.json`, `CombatMood/*AssetFiles.json`, `EncounterReconstruction-2026-11-01/SavedAssets.md`.

이 문서의 원화/축소 비교판 검수는 실제 게임 화면 합격의 대용이 아니다. 실제 접지·투시·크기·먹선과 선택 후 후행 상태는 `RuntimeReview.txt` 및 `Screens`에 별도로 기록한다.
