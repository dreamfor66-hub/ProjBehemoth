## 재비교와 보정

2026-10-28 최종 확인. BeforeAfter.png는 동일한 전투/이벤트 UI의 적용 전후이며,
ReferenceComparison.png는 공식 보상창의 발췌와 Behemoth 이벤트창을 비교한다.

- 1차 HP가 기존 7색 팔레트에서 황토색으로 바뀌었다. 글자와 새 UI 선을 원해상도 레이어에 합성하고 고유색을 보존해 진홍 HP와 청록 MP를 구별했다. 배경/캐릭터의 기존 픽셀 표현은 유지한다.
- 균일한 사각 면을 검은 홈과 이중 레일로 바꿨다. 금색은 제목판의 가는 수평선과 선택 상태에 집중한다. 원작의 대비와 위계를 가져오며 장식용 금장·양피지·과한 광택은 추가하지 않는다.
- 툴팁의 별도 일반 Image도 같은 검은 패널로 교체했다. 지도에 제목이 없을 때 빈 색판을 그리지 않고, 내부 프레임이 범례를 통과하지 않게 했다.
- 선택지의 눌림은 호버의 갈색 면과 구별되는 어두운 청회색으로 보정했다. 카드/주문 슬롯은 기존 선택 상태를 계속 황동 테두리로 표시한다.
- 주문서 제목과 닫기 버튼을 제목판 안에 배치했다. 상점 안내문이 구매 버튼 뒤에 묻히지 않도록 여백을 확보했다.

원작은 네 영웅과 하단 고정 HUD를 사용한다. Behemoth는 후면 전사·실시간 입력과 긴 한글 이벤트를 사용하므로 기존 화면 배치와 읽기 영역을 유지했다. 원작 삽화·장식 이미지를 게임 자산으로 복제하지 않았다.
