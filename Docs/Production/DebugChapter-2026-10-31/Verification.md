# F1 챕터 및 오브젝트 확인 도구

F1 → 챕터에서 1/2/3막의 시작으로 이동한다. 같은 막을 다시 선택해도 새 지도를 만든다. 방문·클리어·발견·열쇠·방 이벤트 기억·상점 재고와 진행 중 전투/선택/이동/지도창을 초기화한다. 장비·성장·골드는 유지하고 HP·방패·피로도를 회복한다. 기존 ForcedSeed가 지정된 검증 환경에서는 그 시드를 존중한다.

오브젝트 17종 중 하나와 방향·사용 전후 상태를 골라 ‘확인방에 배치’를 누르면 현재 막의 확인방으로 이동한다. 오브젝트는 일반 탐험과 동일한 그림·배치·클릭 흐름을 사용한다. 벽 부착물은 실제 막힌 벽에 배치하며 진입한 뒤쪽 벽은 선택할 수 없다. ‘확인방 비우기’로 비울 수 있고 막 시작 버튼으로 일반 랜덤 지도에 복귀한다. 이 확인방 생성은 F1에서만 실행하며 일반 지도 생성 확률/순서를 바꾸지 않는다.

## 실제 Unity 검수

- MainGameScene: **690개 확인, 실패 0** (`Complete.txt`, `Live.txt`).
- Angular01_Main: **102개 확인, 실패 0** (`Trial/Complete.txt`, `Trial/Live.txt`). 저장된 UI 참조와 대표 오브젝트를 확인했다. 이 과거 구도 시험 씬의 고정 배경은 유지했다. 1~3막 최신 배경 검수는 MainGameScene에서 수행했다.
- 카메라로 렌더링되는 실제 Game view에서 버튼 중심의 EventSystem 레이캐스트와 PointerDown/Up/Click 핸들러를 실행했다. 기존 네 탭, 챕터 이동(3→1→2→2→1), 새 시작 방/진행도/장비 유지, 전투/이벤트 중 이동, 사망 후 회복, 지도창 닫힘과 피격 효과 초기화를 확인했다.
- Main에서 세 막 각각 17종 × 미사용/사용 후 그림과 배치 상태를 확인했다. 여신상의 좌우 벽 그림, 뒤쪽 벽 선택 제한, 실제 분수 선택지 열기, 확인방 비우기 및 일반 지도 복귀도 확인했다.
- `ChapterTab.jpg`, `Final-ChapterTab.jpg`, `Act1/2/3-Start.jpg`, `Object-*.jpg`, `Goddess-D1/D3.jpg`는 실제 Unity 캡처다. 최종 챕터 UI에서 한글 잘림/겹침이 없음을 확인했다.
- 최종 두 실행 이후 새 런타임 오류 0바이트. 컴파일 성공. 기존 RewardPopupView.animation의 CS0108 경고는 유지된다.

물리 F1 키 자체는 기존 경로를 유지했고 이번 검수에서는 TogglePanel 진입점을 호출했다. 자동 클릭 중 다른 앱의 키 입력이 섞이지 않도록 해당 실행 동안만 UI 입력 모듈을 잠시 비활성화하고 종료 때 복원했다. 이전 검수 실패 기록은 보존했다. 최종 결과는 위 Complete 파일이 기준이다. 별도 Unity 인스턴스, DPS/밸런스 검사 및 전체 시스템 회귀 검사는 실행하지 않았다.
