## 검증

기존 Unity Editor에서 복제한 연습 데이터와 실제 프레임 시간, production Begin/Move/End 입력 경로로 실행한다. 별도 Unity 인스턴스나 전체 밸런스 검증은 실행하지 않는다.

`Live.txt`에 일반 공격 무효, 차지 파괴, 다중 타격 중간/최종 반응, 선택 약점 유지, 대상 스타일 계승, 파편 확산/컬링/정리와 해골전사·거미·흡혈박쥐·미궁스핑크스의 실제 약점 표시 결과를 기록한다. `Screenshots/`는 실제 게임 화면이다.

가독성 비교: 해골의 밝은 뼈와 금속에는 검정 분리선, 박쥐의 어두운 몸에는 뼈색 외곽과 주홍 중심이 분리를 제공한다. 거미의 몸색/다리와도 표적 실루엣이 구분되고, 스핑크스의 밝은 앞발 및 어두운 날개에서도 같은 표적 의미를 유지한다. 넓은 색면과 선택적 먹선을 기준으로 검토했다.

최종 확인: 19개 항목 PASS, `Live.txt` COMPLETE. 파괴 초반에 실제 메시의 가로·세로 범위가 원래 표적 지름의 2배를 넘는 것과 수명 종료 후 FX 제거를 확인했다. 최초 확인에서 파편의 조기 투명화와 피해 숫자 뒤에서 약하게 읽히는 속도선을 찾아 수정하고 재검증했다. 첫 타격 섬광/파편 확산/후반 소멸은 `BurstSequence-000`부터 `018`까지 실제 Unity 프레임 19장으로 기록했다.

`WeakPointFx-Live.gif`는 표적 상태를 0.7초 보여준 뒤 기록된 간격으로 파괴 프레임을 재생한다. 캡처 영역만 잘랐으며 중간 프레임을 합성하지 않았다. 재생 자료 생성은 `python make_preview.py`.

실기기 터치와 기기별 성능 검증은 미실시. 이번 검증은 데스크톱 Unity의 약점 표시/입력/파괴 동작에 한정한다.
