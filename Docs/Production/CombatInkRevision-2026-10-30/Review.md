# 전투 HUD·먹선 효과 수정

## 바뀐 화면

- **HP/MP는 기존 위치·크기 유지.** 그 위 한 행에 `가드 수치 + 방패/가드 바`와 `공격 + 짧은 검/회복 바`를 나란히 배치했다. 머리 위와 HP 사이에 흩어진 표시를 없애고 왼쪽 상태 열 안에 모았다. 씬에 저장된 오브젝트로 편집 가능하다.
- **가드:** 청록색 발광 테두리와 칸 분할을 없앴다. 작은 철제 방패, 검은 붓자국, 무딘 금속 테두리, 따뜻한 뼛빛 잔량으로 변경했다. 가드 유지 시 밝아지고, 손실은 녹슨 붉은 잔상, 파괴 시 어두운 적갈색으로 구분한다.
- **약점:** 광학 조준경의 정밀한 십자선 대신 굵기와 곡률이 조금 다른 밝은 먹선 고리, 붉은 상처와 짧은 밝은 중심 흔적을 사용한다. 검정 외곽선과 원형 표적의 대비는 유지했다. 파괴 시에도 같은 붓자국이 흩어진다.
- **타격 VFX:** 평행 광선·정원 파동을 없애고, 굵고 휜 먹선 베기와 짧은 충격 흔적으로 바꿨다. 비가드 피해는 어두운 주홍, 가드는 무딘 금속/뼛빛, 완벽한 방어는 옅은 황동색이다. 강타는 더 굵고 오래 남는다. 캐릭터/몬스터 원화를 움직여 포즈를 대신하지 않는다.
- **사망:** `YOU DIED` 페이드 이후 설명 문단 없이 **타이틀로** 하나만 표시한다. 실제 결과 버튼은 OutGameScene의 타이틀 페이지로 돌아간다.
- **몬스터 공격명/남은 시간:** 붓자국과 글씨 크기를 유지하면서 내용의 실제 폭에서 판 너비를 계산한다. 기본 폭의 76% 미만으로 줄이지 않고, 긴 문구는 필요한 만큼 확장한다. 별도의 몬스터별 폭 설정은 추가하지 않았다. 게임플레이 시간은 수정하지 않았다.

## 확인 근거

기존 Unity Editor 한 개에서 변경 범위만 실행했다. `Live.txt`에 가드 유지/손실/파괴, 공격 회복 진행/완료, 마법사 주문 4개와 HUD, 작은 몬스터/인간형/넓은 보스의 표적·이름·시간, 약점 파괴, 실제 AI 일반 공격/강타, 사망→단일 버튼→실제 타이틀 복귀 **31 PASS / 0 FAIL**을 기록했다. 승리 화면의 기존 설명과 버튼 간격도 유지하도록 분리했으며, 최종 결과 화면 확인은 `Results.txt`의 **5 PASS / 0 FAIL**이다. 스크립트 컴파일과 변경 소스의 공백 검사도 통과했다.

`HUD-Review.jpg`, `Combat-Review.jpg`, `Death-Review.jpg`와 원본 PNG에서 위치·색·가림을 육안 검수했다. `Widths.txt`는 실제 문구 폭과 판 너비 기록이다. `LayoutPreservation.json`은 HP/MP의 앵커·위치·크기·스케일을 작업 직전 미저장 씬과 비교한다. `Before/`에는 사용자 편집과 미저장 씬을 보존했다.

첫 캡처의 표본은 약점을 오래 관찰하기 위해 복제 데이터의 준비 시간을 늘렸으므로 `FirstPass/`에 보존했다. 최종 캡처는 표본 몬스터가 실제로 사용하는 준비 시간을 유지한다. 짧은 일반 적 이름판은 560→425.6, 넓은 용 이름판은 370→281.2로 24% 축소됐다. 1자리 초 카운트다운은 312→237.1로 줄면서 여유 여백을 유지한다. 테스트용 HP/공격 간격 변경은 런타임 복제본에만 적용한다.

실제 모바일 기기/다른 화면 비율의 시인성은 미검증이다. 전체 탐험·DPS·밸런스 검증과 추가 Unity는 실행하지 않았다.
