# 상단바 지역명 배치

- `MainGameScene`의 StageTitle을 ArcadeStatus 자식으로 저장하고 화면 중앙에 배치했습니다.
- HP와 골드는 왼쪽 두 줄로 정리했고, 물약 퀵슬롯은 왼쪽 상태 영역 아래로 옮겼습니다.
- 기존 한국어 키와 스테이지별 텍스트 갱신 로직을 유지합니다.

## 확인

| 항목 | 결과 |
| --- | --- |
| Unity Play: B1 지역명 중앙 배치 | 확인 |
| HP·골드·지도·보유품·메뉴 간격 | 실행 화면 확인 |
| 물약 3개 보유 시 퀵슬롯 위치 | 런타임 RectTransform 확인, 중앙 제목 영역과 분리 |
| 저장된 씬 부모/자식 참조 | 확인 |

물약 슬롯 클릭 검증과 B2/B3 이름의 실행 화면 확인은 미실시입니다. 이 변경은 레이아웃만 수정합니다.
