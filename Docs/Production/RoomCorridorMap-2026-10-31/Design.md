# 방과 통로로 나뉜 미궁 지도

사용자가 2026-10-31 제공한 기존 지도 캡처와 Darkest Dungeon 지도 참고 이미지 3장을 구조 참고로 사용한다. 별도 아트 생성 없이 큰 목적지 방, 작은 통로 사건, 그 사이 바닥 타일과 여백을 만든다.

## 요구 사항

- [x] 주요 장소와 작은 사건의 크기 구분. 보스/정예/상자/상점/야영/여신/선택 이벤트/입구는 큰 방, 일반 전투/샘/소규모 보상/빈칸은 작은 통로 셀.
- [x] 분류와 크기를 `DungeonMapStyle` 데이터에서 수정 가능. 방별 중복 플래그 없이 사건 종류에서 표현을 계산.
- [x] 큰 방 50, 통로 사건 24, 중심 간격 84, 연결 바닥 타일 10. 굵은 십자 연결선을 제거.
- [x] 짧은 통로를 이어 배치하고, 연결되지 않은 길이 옆으로 맞붙거나 2×2 블록으로 뭉치는 배치를 금지. 루프는 떨어진 경로 사이에서만 명시적으로 연결.
- [x] 방 수/보상/이벤트 개수 설정과 B1 초반 전투/거리/분기 제한 유지. 시드별 지도 형태는 새로 생성됨.
- [x] 선택 가능 셀의 클릭 영역 최소 44, 현재 위치 화살표/선택 강조/미탐험 상태/완료 상태.
- [x] 지도 드래그/휠 확대·축소/내 위치 복귀. 장거리 경로를 자동 축소하지 않음.
- [x] MainGameScene과 Angular01_Main에 저장된 UI 및 데이터 참조. 수동 베이크 메뉴 불필요.
- [x] 현재 Unity Editor의 실제 맵 화면 검토와 입력 검증. EditMode 4개 및 런타임 21개 통과. 상세 범위는 Verification.md.
