## 같은 석재에 대한 실제 샘플 비교

원본 스크린샷의 RGB를 그대로 읽었다. 왼쪽 가까운 기둥 면, 오른쪽 가까운 기둥 그늘, 왼쪽 중간 바닥의 정규화된 작은 영역을 사용했다. UI·불꽃을 피했고 대표 RGB는 채널 중앙값이다. 상대 명도Y는 각 픽셀을 linear sRGB로 변환한 뒤 `0.2126R + 0.7152G + 0.0722B`의 중앙값이다. 샘플 좌표·원본 해시는 JSON에 있다. 레이아웃·뷰포트·광원 차이가 있어 정확한 텍스처 캘리브레이션이나 보편 합격 임계값으로 사용하지 않는다.

|B1 화면|왼쪽 기둥 RGB / Y|오른쪽 기둥 그늘 RGB / Y|중간 바닥 RGB / Y|
|---|---|---|---|
|승인 원본1|103,93,67 / .11130|32,32,31 / .01455|72,67,54 / .05658|
|허용2|103,90,64 / .10566|32,32,30 / .01439|70,65,48 / .05296|
|허용3|103,91,64 / .10736|33,32,31 / .01472|63,59,45 / .04342|
|거부4|70,59,35 / .04551|29,25,16 / .00994|55,46,28 / .02850|
|거부5|70,59,35 / .04551|29,25,16 / .00991|71,56,37 / .04334|

이 비교에서 거부본은 단순히 ‘더 밝고 노랗다’가 아니다. 가까운 기둥 명도가 크게 내려가면서 재료색의 파랑이 더 강하게 줄고, 그늘의 중립성도 사라진다. 허용본 오른쪽 그늘은 대략32,32,30인 반면 거부본은29,25,16이다. 바닥도 비슷한 방향이다. 그러므로 노출만 낮추거나 색온도를 단어로 평가해서 통과시키면 이 오류를 놓친다. 반대로 모든 방을 숫자상 원본과 똑같이 만들라는 결론도 아니다. 실제 광원과 재료 면이 바뀐 경우에는 해당 이유와 위치를 함께 비교한다.

Root는 원인 조사에서 이미 온색으로 그려진 공용 서약실에 `useFloorLighting=true`의 B1 tint가 추가로 곱해지고, 문틀에는 같은 처리가 적용되지 않는 경로를 확인했다고 공유했다. 새 막별 팔레트와 공통 적용 방식은 root가 교정 중이다. 이 문서 작성자는 생산 PNG나 런타임 코드를 바꾸지 않았다. 결과는 **새 합성된 기본 방/변주/문/사물 화면**에서 다시 판단하며 원인 추정만으로 해결됐다고 쓰지 않는다.

## 실행 가능한 지침으로 반영한 내용

- 상세 필수 기준: `Assets/Art/References/DarkestDungeonVisual/STYLE_GUIDE.md`.
- `Assets/Art/AGENTS.md` 맨 위에 최신 실제 DD 시각 기준과 합성 검수 요구를 추가했다.
- AngularCharacterStyle/AngularMonsterStyle 안내에 최신 DD 분위기 지침을 연결했다. 기존 원본의 형태·승인 정체성 역할과 DD의 분위기·빛 역할을 나눴다.
- 프로젝트 `AGENTS.md`에 같은 기준의 짧은 참조를 추가했다.
- 큰 먹면·어두운 바탕·이유 있는 빛·읽히는 초점·낡은 큰 형태를 동시에 요구한다. ‘clean’을 공장처럼 매끈한 벡터 표면으로, ‘낡음’을 잔균열/노이즈의 양으로 바꾸지 않는다.
- 승인된 플레이어의 얼굴·장비·포즈·크기와 B1 투시/바닥을 보호한다. 배경 교정의 실패를 배우 재설계로 덮지 않는다.
- 같은 재료의 RGB/명도 비교와 실제 접합선 검수를 필수화했다. 샘플 수치만으로 통과시키는 임계값은 만들지 않았다.
- 고립 PNG, 프롬프트, 컴파일, 단순 어둡게 하기만으로 통과를 선언하지 않는다. 관련 막/방향/사용 상태의 실제 크기 합성 화면이 있어야 한다.

## 후속 독립 검수 상태

사용자 참고 원본과 기존 허용/거부 화면의 조사 및 지침 반영을 마친 뒤, 새 생산 배경6장과 실제 Unity 합성24장을 독립 검수했다. [IndependentSourceReview.md](IndependentSourceReview.md), [IndependentRuntimeReview.md](IndependentRuntimeReview.md)에 범위와 근거를 기록했다. 전역 황색 이탈은 교정됐지만 B1 우측 측문의 직사각형 밝은 합성 패치를 발견해 반려하고 root에 위치·RGB/Y를 전달했다. 이후16:06:11 설치보다 새로운 B1 실제 화면9장을 직접 재확인했으며 기존 패치 해소 및 새 좌우 문틀의 색·위치를 통과시켰다. 과거 실패와 교정 후 파일 시각·해시는 각각 보존했다. 생산 파일이나 Unity 상태를 바꾸지는 않았다. 기존 `WorldRenewal/IndependentWorldArtReview.md`의 색 조화 평가는 그때 확인한 표본 범위에 한하며 이번 사용자 거부4/5까지 포괄적으로 승인한 근거로 사용하지 않는다.
