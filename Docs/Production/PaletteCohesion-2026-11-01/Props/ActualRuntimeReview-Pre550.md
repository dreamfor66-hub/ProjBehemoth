# 실제 Unity 최종 화면 검수

검수자는 Unity를 조작하지 않고 `Screens/Final-*.jpg`의 실제1920×1080 GameView27장을 직접 열어 확인했다. 앞선 PNG 합성 보드나 자동 검사 통과를 이번 시각 판정의 근거로 대체하지 않았다. 아트·코드·배치 데이터는 변경하지 않았다.

여신상은 기존의 금색 성물보다 주변 석조 구조물에 가깝게 읽힌다. B1/B3 횃불 아래에서는 회색 석재도 따뜻해지지만, 벽·기둥의 명도와 연결되고 광택 있는 금색 베벨로 분리되지 않는다. B2에서는 동일 그림이 청회색 건축과 연결된다. 후드·그릇·옷 안쪽의 검은 면과 주변 먹선의 밀도도 맞는다. 정면의 하부가 플레이어 뒤에 가려지는 깊이 관계는 자연스럽고 얼굴·그릇은 남는다.

분수18샷에서는 젖은 상태의 수면·작은 물줄기와 마른 그릇이 구별된다. Ready→Used 비교에서 림의 큰 파임, 기둥, 단과 바닥 접점이 같은 자리에 남고 그릇이 튀거나 커지지 않는다. 넓은 검은 아랫면과 절제된 회색 면이 바닥·배경 먹선과 연결되며, 물이 보석처럼 발광하거나 외곽에 후광이 뜨지 않는다. view1의 우측 화살표가 림 일부를, 검이 낮은 단 일부를 가리지만 물구멍·물줄기·주요 실루엣은 읽힌다. 이는 현재 탐험 UI/전경 겹침으로 기록하며 새 그림의 구조 불일치로 판정하지 않았다.

## 수정이 필요한 실제 결함

**B3 여신상 측면의 후드 꼭대기가 HUD 하단에 잘린다.**

- `Screens/Final-B3-Goddess-1-Ready.jpg`
- `Screens/Final-B3-Goddess-3-Ready.jpg`

두 샷에서 후드의 삼각 꼭대기가 화면 y≈118의 검은 HUD 하단에서 수평으로 끊긴다. B1/B2의 같은 측면에서는 후드 끝과 위쪽 여백이 모두 보인다. 실제 캡처 부분을 같은 배율로 나란히 둔 [상단 비교](Actual-Goddess-HUD-Crops.jpg)로 재확인했다. 그림의 색·알파 결함과 구분되는 B3 측면 배치/화면 여유 문제다. 루트에 보고했으며 이번 검수에서 수정하지 않았다.

이1건 때문에 모든 화면을 최종 통과했다고 기록하지 않는다. 수정 후 같은 두 실제 GameView에서 후드 끝이 온전히 보이는지 재확인해야 한다. 이번 검수는 해당 고정 캡처의 시각 검수이며, 클릭·대사·재방문 동작의 실행 결과는 루트 런타임 기록을 따른다.
