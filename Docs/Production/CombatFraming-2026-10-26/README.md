# 전투 깊이와 HUD 얼굴 구도

- 몬스터 생성 기준 높이: 105 → 170 (+65 논리 좌표). 그림만 이동하지 않고 적의 실제 기준 위치를 올려 타격/약점 위치도 따라간다.
- 같은 전투 영역 안에서 MonsterSpawnRoot를 PlayerSpawnRoot보다 먼저 그린다. 이름/HP/약점/피격 효과의 개별 표시 기능은 유지한다.
- HUD 초상화 6종은 기존 640px PNG의 얼굴 부분만 픽셀 크롭했다. 캐릭터 그림 원본과 선택창 이미지는 변경하지 않았다. 출력: Assets/Art/UI/Portraits/Angular/.
- FatigueHUD를 전체 캔버스 가장자리로 맞춰 고정 폭 부모 때문에 생기던 좌우 인셋을 제거했다. 초상화 크기와 옆 HP 정보 위치는 유지한다.
- 저장된 씬/스프라이트로 동작한다. 자동 준비 코드는 Editor/Presentation/CombatFramingPreparation.cs. 수동 메뉴 작업 불필요.

검증: 기존 Unity Editor에서 6종 얼굴 크롭과 좌측 정렬, 렌더 순서, 납골 전갈 표시, 이동한 약점 좌표의 화면 입력 변환과 실제 강타 판정을 검사했다. Live.txt와 Screenshots/에 기록한다. 밸런스/다른 기능의 회귀 검증은 이번 범위에 포함하지 않았다.

이미지를 새로 생성하지 않았다. 기존 아트의 결정론적 크롭이며 이미지 생성 프롬프트 없음.

로그의 미인지 표시는 몬스터를 올리면서 위쪽 줄이 헤더에 잘리는 것을 막기 위해 이름 앞 같은 줄에 배치했다. 후속 로그 전투 캡처에서 전체 문구가 보이는 것을 확인했다. 제작 중 Play 전환과 겹친 준비 작업은 Edit 모드 재진입 후 완료했으며 Preparation-Resolved.txt는 해결된 초기 기록이다.
