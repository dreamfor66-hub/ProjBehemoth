# 로그 시작 유물: 그림자 망토

## 요구사항

- [x] 시작 유물의 자동 독 부여를 은신으로 교체한다.
- [x] 조우마다 은신 및 행동 수를 초기화한다.
- [x] 준비·대기 시간에는 적의 일반/차지 타이머와 행동을 진행하지 않는다.
- [x] 첫 행동의 차지·긴 캐스팅 준비를 자유롭게 할 수 있다.
- [x] 행동 완료 후 발각 확률은 25%, 50%, 75%, 100%다. 매번 별도 판정하며 확률은 퍼센트포인트로 증가한다.
- [x] 적 한 마리라도 공격받으면, 그 공격이 치명타거나 방향 방벽에 막혀도 무리 전체가 즉시 알아차린다.
- [x] 발각되면 기존 간격 및 개체별 지연을 유지한 타이머가 진행한다. 은신 중 쿨타임이 쌓이지 않는다.
- [x] 공격·주문·포션·방어 종료를 센다. 차지/캐스팅 준비, 실패한 공격 요청·주문, 접촉 취소는 세지 않는다.
- [x] 주문 발사와 방어 해제를 중복 집계하지 않는다. 두 접촉을 번갈아 떼고 다시 눌러도 마지막 방어가 끝날 때만 판정한다.
- [x] 다른 5개 직업은 기존 타이머·조우 안내·상태 UI를 유지한다. 발각 난수도 추가 소비하지 않는다.
- [x] 로그 기존 수치 유지: 체력 75, 가드 18, 일반 5.5, 차지 17, 공격 간격 0.48초, 차지 준비 0.65초.
- [x] TextMeshPro, 한국어 키 및 CSV를 사용한다. 은신 상태·다음 판정 확률·미인지·발각 피드백을 표시한다.

## 데이터 편집과 확장

`Assets/Data/Behemoth/Relics/Starter_Rogue.asset`의 `Abilities`:

- `Passive → OwnerStat → RuleModifier / EncounterConcealment = 1`
- `Passive → OwnerStat → RuleModifier / DetectionChancePerAction = 0.25`

효과는 캐릭터나 아이템 이름으로 분기하지 않는다. 다른 장비에도 같은 규칙을 조합할 수 있다.
조건 `OwnerConcealed`, `EncounterActions`와 트리거 `OnActionCompleted`, `OnEncounterRevealed`를 추가하여 후속 유물을 작성할 수 있다. 이번 작업에서 파생 유물을 새로 추가하지는 않았다.

## 검증

Unity 6000.0.59f2의 열린 에디터에서 `EnterPlayMode`로 실제 프레임과 기존 입력 경로를 실행했다.
첫 집중 검증: 11개 통과. 기록은 `Logs/Behemoth-StealthTestResults.xml`, `Logs/Behemoth-StealthPlaytestMatrix.txt`.

전체 회귀 검증: **154개 중 153개 통과, 1개 실패**. 실패는 `Balance_SixCoreLoops_SustainedDpsProbe_AndVisibleDog`의 기존 로그/워리어 지속 DPS 비율 0.75 이상 조건이다. 실제 결과는 로그 11.36, 워리어 16.33 DPS로 비율 0.696이었다. 은신 준비 이득을 쓰지 않는 30초 연속 공격 조건이며, 독 기본 부여 제거에 따른 밸런스 차이다. 기준을 낮춰 테스트를 통과시키거나 요청된 기본 스탯을 바꾸지 않았다.

실제 엘리트 비교도 3막 × 6직업을 기록했다. 예를 들어 B1 로그는 34.17초에 체력 소진(적 피해 354), 워리어는 29.13초에 처치했다. B3 로그는 38.01초, 워리어는 27.07초에 처치했다. 이 자동 입력 정책은 새 은신 차지 개시를 활용하지 않으므로, 인간 플레이 및 준비 빌드의 강도를 확정하는 자료는 아니다. 전체 결과: `Logs/Behemoth-StealthFullRegression.xml`, `Logs/Behemoth-StealthFullPlaytestMatrix.txt`, `Logs/Behemoth-BalanceMatrix.txt`.
